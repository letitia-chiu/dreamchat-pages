智慧輔助設定技巧

對應版本：v2.8.0

這份說明給正在整理字卡庫、字卡組與觸發關鍵字的使用者。智慧輔助會依照收到的新訊息，從字卡組名稱、適用情境、觸發關鍵字與字卡內容中找出最適合的字卡組；其中「觸發關鍵字」是最明確、最適合用來引導話題的訊號。

先記住三件事 模式怎麼選 關鍵字怎麼寫 快速檢查 常見問題

1. 先記住三件事

  1. 關鍵字要寫「你可能會傳給角色的話」，不是角色要回覆的話。
  2. 越獨特、越像一個完整情境的關鍵字，越容易接對字卡組。
  3. 太短、太常見、到處都會出現的字，容易讓判斷變模糊。

智慧輔助主要用本次新收到的使用者輪次做判斷。若你連續傳出幾則短訊息，中間沒有角色回覆，系統會把短時間內的連續使用者訊息一起視為本輪脈絡；引用回覆或承接角色上一句話時，舊內容只會作為弱情境脈絡。

2. 智慧輔助模式怎麼選

  • 「關閉」：不做字卡組智慧判斷，回到一般字卡選擇。
  • 「自然」：預設建議。明確命中會穩定選組；多個合理情境分數接近時，會自然分岔。
  • 「精準」：優先固定選最高分字卡組，適合想要最穩定分類的角色。
  • 「多變」：放寬合理候選範圍，讓同一句開放式訊息更容易出現不同情境。

「智慧輔助」決定主要字卡組怎麼選；「隨機性」是在主要字卡組選定後，決定要不要混入通用或其他字卡。隨機性調低時，已選定主要字卡組之後仍只會從該組抽卡；但在自然或多變模式下，主要字卡組本身可能在多個合理字卡組之間分岔。

3. 關鍵字怎麼寫

用自然會出現在訊息裡的詞

把自己代入聊天現場，想像使用者真的會怎麼說。比起只寫「安慰」，更適合寫「我今天好累」「壓力很大」「想哭」「被罵了」。比起只寫「睡覺」，更適合寫「晚安」「睡不著」「熬夜」「夢到你」。

優先放獨特名詞與完整短句

角色名、暱稱、作品名、地名、事件名，或只有某個字卡組才會用到的詞，都很適合放進觸發關鍵字。像 你是不是吃醋、我夢到你、被主管罵、明天考試，都比單獨的 好、你、累 更能判斷情境。

一個字卡組放多個角度

比起只放一條完整句子，通常更適合放 5 到 12 個會從不同角度碰到同一情境的關鍵字。例如「睡前陪伴」可以放 晚安、睡不著、熬夜、想睡了、夢到你、今晚來夢裡。

相似字卡組要放差異點

如果有「和你去旅行」與「和朋友去旅行」兩組，請把 你、朋友、我們、同學 這類能區分方向的詞寫清楚。中文互動句也建議把方向寫完整，因為 你哄我 和 我哄你、你幫我 和 我幫你 是完全不同的情境。

適用情境補脈絡，觸發關鍵字放決定性線索

「適用情境」適合寫一段人看得懂的說明，例如這組字卡在什麼情緒、什麼場景、什麼關係中使用。「觸發關鍵字」則適合放最可能直接命中的詞，例如你真的可能輸入的短句、名詞、暱稱與情境線索。

不要只靠字卡內容來觸發。字卡是「角色要回覆的話」，不一定等於「你會傳給角色的話」。重要字卡組請補上字卡組名稱、適用情境與觸發關鍵字。

4. 快速檢查清單

  • 這些關鍵字是不是你或聊天者真的可能輸入的話？
  • 有沒有至少幾個兩字以上、比較獨特的詞？
  • 有沒有避開只用 好、嗯、你、我、今天 這類泛用詞？
  • 相似字卡組之間，有沒有寫出真正的差異點？
  • 字卡組本身有沒有足夠的字卡可抽？

5. 常見問題

明明有設定，卻沒有接到這組？

先把實際觸發回覆的那句話加入觸發關鍵字，或拆成幾個更自然的短句。也可以檢查這組是否只有很泛的詞，像「累」「今天」「不開心」，需要補上更具體的情境。

接到正確字卡組，但偶爾回覆還是偏題？

這通常和「隨機性」有關。智慧輔助先選出最符合的字卡組，隨機性再決定要不要混入通用或其他字卡組。想讓回覆更穩定，可以把隨機性調低，並增加該字卡組裡可用的回覆。

Apple Intelligence 會幫我生成回覆嗎？

不會。智慧輔助只會選擇既有字卡組，再從字卡庫中抽取回覆。系統可能會在裝置端使用 Apple 提供的語言處理框架，例如 Natural Language framework，以及在相容裝置上的 Apple Intelligence / Foundation Models，協助選擇較合適的分類；它不會替角色生成新的對話內容，也不會把聊天訊息、字卡文字、觸發關鍵字或分類結果上傳至開發者伺服器。

智能辅助设置技巧

对应版本：v2.8.0

这份说明适合正在整理字卡库、字卡组与触发关键词的用户。智能辅助会依据收到的新消息，从字卡组名称、适用情境、触发关键词与字卡内容中找出最适合的字卡组；其中「触发关键词」是最明确、最适合用来引导话题的信号。

先记住三件事 模式怎么选 关键词怎么写 快速检查 常见问题

1. 先记住三件事

  1. 关键词要写「你可能会发给角色的话」，不是角色要回复的话。
  2. 越独特、越像一个完整情境的关键词，越容易接对字卡组。
  3. 太短、太常见、到处都会出现的字，容易让判断变模糊。

智能辅助主要用本次新收到的用户轮次做判断。若你连续发出几条短消息，中间没有角色回复，系统会把短时间内的连续用户消息一起视为本轮上下文；引用回复或承接角色上一句话时，旧内容只会作为弱情境上下文。

2. 智能辅助模式怎么选

  • 「关闭」：不做字卡组智能判断，回到一般字卡选择。
  • 「自然」：默认建议。明确命中会稳定选组；多个合理情境分数接近时，会自然分岔。
  • 「精准」：优先固定选最高分字卡组，适合想要最稳定分类的角色。
  • 「多变」：放宽合理候选范围，让同一句开放式消息更容易出现不同情境。

「智能辅助」决定主要字卡组怎么选；「随机性」是在主要字卡组选定后，决定要不要混入通用或其他字卡。随机性调低时，已选定主要字卡组之后仍只会从该组抽卡；但在自然或多变模式下，主要字卡组本身可能在多个合理字卡组之间分岔。

3. 关键词怎么写

用自然会出现在消息里的词

把自己代入聊天现场，想象用户真的会怎么说。比起只写「安慰」，更适合写「我今天好累」「压力很大」「想哭」「被骂了」。比起只写「睡觉」，更适合写「晚安」「睡不着」「熬夜」「梦到你」。

优先放独特名词与完整短句

角色名、昵称、作品名、地名、事件名，或只有某个字卡组才会用到的词，都很适合放进触发关键词。像 你是不是吃醋、我梦到你、被主管骂、明天考试，都比单独的 好、你、累 更能判断情境。

一个字卡组放多个角度

比起只放一条完整句子，通常更适合放 5 到 12 个会从不同角度碰到同一情境的关键词。例如「睡前陪伴」可以放 晚安、睡不着、熬夜、想睡了、梦到你、今晚来梦里。

相似字卡组要放差异点

如果有「和你去旅行」与「和朋友去旅行」两组，请把 你、朋友、我们、同学 这类能区分方向的词写清楚。中文互动句也建议把方向写完整，因为 你哄我 和 我哄你、你帮我 和 我帮你 是完全不同的情境。

适用情境补上下文，触发关键词放决定性线索

「适用情境」适合写一段人看得懂的说明，例如这组字卡在什么情绪、什么场景、什么关系中使用。「触发关键词」则适合放最可能直接命中的词，例如你真的可能输入的短句、名词、昵称与情境线索。

不要只靠字卡内容来触发。字卡是「角色要回复的话」，不一定等于「你会发给角色的话」。重要字卡组请补上字卡组名称、适用情境与触发关键词。

4. 快速检查清单

  • 这些关键词是不是你或聊天者真的可能输入的话？
  • 有没有至少几个两字以上、比较独特的词？
  • 有没有避开只用 好、嗯、你、我、今天 这类泛用词？
  • 相似字卡组之间，有没有写出真正的差异点？
  • 字卡组本身有没有足够的字卡可抽？

5. 常见问题

明明有设置，却没有接到这组？

先把实际触发回复的那句话加入触发关键词，或拆成几个更自然的短句。也可以检查这组是否只有很泛的词，像「累」「今天」「不开心」，需要补上更具体的情境。

接到正确字卡组，但偶尔回复还是偏题？

这通常和「随机性」有关。智能辅助先选出最符合的字卡组，随机性再决定要不要混入通用或其他字卡组。想让回复更稳定，可以把随机性调低，并增加该字卡组里可用的回复。

Apple Intelligence 会帮我生成回复吗？

不会。智能辅助只会选择既有字卡组，再从字卡库中抽取回复。系统可能会在设备端使用 Apple 提供的语言处理框架，例如 Natural Language framework，以及在兼容设备上的 Apple Intelligence / Foundation Models，协助选择较合适的分类；它不会替角色生成新的对话内容，也不会把聊天消息、字卡文字、触发关键词或分类结果上传至开发者服务器。

スマートアシスト設定のコツ

対応バージョン：v2.8.0

このページは、定型文集、定型文セット、トリガーキーワードを整理する方向けです。スマートアシストは、新しく受信したメッセージをもとに、セット名、使う場面、トリガーキーワード、定型文の内容から、より合う定型文セットを選びます。特に「トリガーキーワード」は、話題を導くためのもっとも明確な手がかりです。

基本 モード キーワード チェック よくある質問

1. まず覚えておきたいこと

  1. キーワードには「ユーザーがキャラクターに送りそうな言葉」を入れます。キャラクターが返す言葉ではありません。
  2. 具体的で、ひとつの場面が想像できるキーワードほど、合う定型文セットを選びやすくなります。
  3. 短すぎる言葉や、どこにでも出る言葉だけだと、判断があいまいになります。

スマートアシストは主に、今回新しく届いたユーザー側の発話を見て判断します。キャラクターの返信をはさまず短いメッセージを続けて送った場合、その短時間の連続メッセージも同じ文脈として扱われます。引用返信や直前のキャラクター発話は、弱い文脈としてだけ使われます。

2. モードの選び方

  • 「オフ」：スマートな定型文セット選択を使わず、通常の選択に戻します。
  • 「自然」：おすすめの初期設定です。明確な一致は安定して選び、複数の自然な場面が近いときは自然に分岐します。
  • 「精密」：もっとも高いスコアのセットを優先します。安定した分類にしたいキャラクターに向いています。
  • 「多彩」：妥当な候補を少し広げ、同じ開かれたメッセージでも違う場面が出やすくなります。

スマートアシストは、どの primary 定型文セットを選ぶかを決めます。「ランダム性」は、その primary が決まった後に、基本セットや他のセットを混ぜるかどうかに影響します。

3. キーワードの書き方

実際のメッセージに出そうな言葉を使う

チャットの場面を想像し、ユーザーが本当に送りそうな表現を書きます。「慰め」だけより、今日すごく疲れた、つらい、泣きそう のような言葉のほうが判断しやすくなります。

固有名詞や短い文を優先する

キャラクター名、あだ名、作品名、場所、イベント名、その定型文セットだけで使う言葉は良い手がかりです。やきもち焼いてる？、夢に出てきた、明日テスト のような短い文は、単語だけより場面を伝えやすくなります。

ひとつのセットに複数の角度を入れる

1つの長い文だけを入れるより、同じ場面に触れるキーワードを 5 から 12 個ほど入れるのがおすすめです。たとえば「寝る前の会話」なら、おやすみ、眠れない、夜更かし、夢に出てきて などを入れます。

似たセットには違いが分かる言葉を入れる

似た定型文セットがある場合は、違いを表す言葉を明確にします。日本語や中国語の会話では、誰が誰にするのかも大切です。たとえば「私をなぐさめて」と「あなたをなぐさめたい」は、別の場面として分けて書くと安定します。

使う場面とトリガーキーワードを分ける

「使う場面」には、人が読んで分かる説明を書きます。「トリガーキーワード」には、実際にメッセージに出そうな短い文、名詞、あだ名、場面の手がかりを入れます。

定型文の本文だけに頼らないでください。定型文は「キャラクターが返す言葉」であり、「ユーザーが送る言葉」とは限りません。大切なセットには、セット名、使う場面、トリガーキーワードを入れておくと安定します。

4. チェックリスト

  • そのキーワードは、ユーザーが実際に送りそうな言葉ですか？
  • 具体的で、2文字以上の手がかりがいくつか入っていますか？
  • 「うん」「はい」「私」「あなた」「今日」だけに頼っていませんか？
  • 似たセット同士で、違いが分かる言葉を入れていますか？
  • その定型文セットには、十分な定型文がありますか？

5. よくある質問

設定したのに、そのセットが選ばれません。

実際に送ったメッセージを、そのまま、またはいくつかの自然な短い言葉に分けてトリガーキーワードへ追加してください。一般的すぎる言葉だけになっていないかも確認します。

正しいセットは選ばれるのに、たまに返信がずれます。

多くの場合は「ランダム性」の影響です。より安定させたい場合はランダム性を下げ、そのセット内で使える定型文を増やしてください。

Apple Intelligence が返信文を生成しますか？

いいえ。スマートアシストは既存の定型文セットを選び、定型文集から返信を選ぶだけです。端末上で Apple の Natural Language framework や、対応端末では Apple Intelligence / Foundation Models を分類補助に使う場合がありますが、新しい会話文は生成せず、チャットメッセージ、定型文本文、トリガーキーワード、分類結果を開発者のサーバーへアップロードすることもありません。

Smart Assist Setup Tips

Applies to version v2.8.0

This page helps you tune chat phrase libraries, phrase sets, and trigger keywords. Smart Assist uses the latest incoming message, phrase set name, usage context, trigger keywords, and chat phrase text to choose the most relevant phrase set. Trigger keywords are the clearest signal for guiding a topic.

Basics Modes Keywords Checklist FAQ

1. Three Things to Remember

  1. Write what you might send to the character, not what the character should say back.
  2. Specific keywords that feel like a complete situation are easier to match.
  3. Very short or very common words can make the decision ambiguous.

Smart Assist mainly evaluates the current user turn. If you send several short messages before the character replies, DreamChat treats those nearby user messages as the current context. Quoted replies or the character's previous message are used only as weaker context.

2. Choosing a Smart Assist Mode

  • Off: returns to regular phrase selection without Smart Assist phrase-set judgment.
  • Natural: the recommended default. Clear matches stay steady; close reasonable contexts can branch naturally.
  • Precise: favors the top-scoring phrase set, useful when you want the most stable classification.
  • Varied: allows a wider reasonable candidate pool so open-ended messages can vary more.

Smart Assist decides which primary phrase set to use. Randomness applies after that choice, controlling whether replies can mix in General or other phrase sets. Lower randomness keeps replies steadier; Natural or Varied can still choose between several reasonable primary sets when their scores are close.

3. Writing Better Keywords

Use words that would appear in a real message

Think like the person chatting. Instead of only writing "comfort," use phrases like I'm tired today, I'm stressed, I want to cry, or I got scolded. Instead of only writing "sleep," use good night, I can't sleep, stayed up late, or dreamed about you.

Prioritize unique nouns and short complete phrases

Character names, nicknames, titles, places, events, and words that only belong to one phrase set are strong clues. Phrases like are you jealous, I dreamed about you, my manager scolded me, or exam tomorrow usually work better than single common words.

Add several angles to one phrase set

Instead of one long sentence, add 5 to 12 natural variations that point to the same situation. For a bedtime set, you might include good night, I can't sleep, staying up late, I'm sleepy, dream about you, and come to my dream tonight.

Give similar sets clear differences

If two sets are similar, write the words that separate them. For Chinese interaction direction, write the subject and object clearly: you comfort me and I comfort you, or you help me and I help you, are different situations.

Use context for background and keywords for decisive clues

Usage Context is best for a readable description of the emotion, scene, or relationship where a phrase set should be used. Trigger Keywords are best for short phrases, nouns, nicknames, and situation clues that may appear directly in a message.

Do not rely only on chat phrase text. Chat phrases are what the character says back; they may not match what you would send to the character. For important phrase sets, fill in the set name, usage context, and trigger keywords.

4. Quick Checklist

  • Are these keywords things you or the other chatter might actually type?
  • Do you have several specific keywords longer than one character or word?
  • Are you avoiding relying only on common words like okay, you, me, or today?
  • Do similar phrase sets include the words that make them different?
  • Does the phrase set have enough chat phrases to draw from?

5. FAQ

I set it up, but this phrase set was not chosen.

Add the actual message that triggered the reply to Trigger Keywords, or split it into a few natural short phrases. Also check whether the set only uses broad words like "tired," "today," or "sad"; those usually need more specific context.

The right phrase set is chosen, but some replies still drift.

That is usually related to Randomness. Smart Assist chooses the best phrase set first; Randomness then decides whether General or other phrase sets can mix in. Lower Randomness and add more usable phrases inside the matched set for steadier replies.

Does Apple Intelligence generate replies?

No. Smart Assist only chooses from existing phrase sets, then DreamChat draws from your chat phrase library. The app may use Apple-provided language processing frameworks, such as the Natural Language framework, and on compatible devices Apple Intelligence / Foundation Models, on device to help choose a category. It does not generate new conversation text, and it does not upload chat messages, chat phrase text, trigger keywords, or classification results to the developer's servers.
