DreamChat 使用說明

對應版本：v3.1.0

這份說明給第一次使用 DreamChat 的使用者。你可以先從聊天開始，再慢慢整理角色、字卡庫、語音訊息、定時來訊與貼圖。

快速開始 聊天 角色 字卡庫 語音訊息 情境標籤 定時來訊 天氣提醒 視訊通話 貼圖 權限 設定與備份

1. 第一次打開 App

  1. DreamChat 會先建立一位預設角色與一個預設對話。
  2. 底部有三個主要分頁：「角色」、「聊天」、「設定」。
  3. 想立刻開始，進入「聊天」分頁，打開對話，在底部輸入訊息後按紙飛機送出。

角色的自動回覆會從「字卡庫」抽取。還沒想好怎麼設定時，可以先到 角色 → 角色設定 → 字卡庫 → 匯出／匯入 → 套用預設範本 匯入範本字卡庫；如果只想先得到簡短答案，也可以先使用 是否模式。

2. 聊天分頁怎麼用

「聊天」分頁會列出最近對話。點進對話後，你可以：

  • 在底部輸入文字並送出。
  • 按表情按鈕開啟貼圖與表情符號。
  • 按放大鏡搜尋目前對話的訊息，或依日期跳轉。
  • 長按訊息可回覆、複製、截圖或刪除；截圖預覽可切換原始或匿名模式。
  • 上方選單可切換「聊天模式」與「是否模式」，也可以使用「幫我選」。更多差異請看 聊天模式專欄。
  • 上方選單也能開啟角色設定、群組設定、目前情境，或暫停此對話的定時來訊。
  • 一對一聊天可使用視訊通話入口，或請角色稍後來電；聊天中也可用關鍵字詢問目前天氣。

如果想逐一認識聊天室工具列、搜尋、訊息長按選單、截圖與輸入列，請看 聊天室畫面導覽。

3. 建立與管理角色

到「角色」分頁，按右上角加號可以「新增角色」或「匯入角色」。點進角色後可調整：

  • 角色名稱、聊天室背景、是否顯示已讀與自己的頭像。
  • 回覆時間，例如最短與最長延遲。
  • 聊天模式：一般「聊天模式」或「是否模式」。
  • 字卡庫、語音訊息、貼圖使用設定、定時來訊、天氣提醒與視訊通話。
  • 右上角分享按鈕可匯出角色分享檔。

要新增對話，請到「聊天」分頁按加號，選擇「直接」或「群組」。群組對話至少需要兩位可用角色，且必須是目前方案支援的功能。

4. 設定字卡庫，讓角色會回覆

路徑：角色 → 角色設定 → 字卡庫

  • 「通用」是預設字卡組；你也可以新增自訂字卡組。
  • 進入字卡組後，按「新增回覆字卡」，每行輸入一張字卡。
  • 如果目前沒有靈感，可以在字卡庫頁面右上角按「匯出／匯入」托盤圖示，選「套用預設範本」。接著選擇範本語言（繁體中文、简体中文、日本語或 English），再選擇「追加」或「取代」。範本目前每種語言各有 260 張字卡。
  • 「追加」會保留目前字卡庫並補入未重複內容；「取代」只會取代同名字卡組，沒有匹配到的本機字卡組會保留。
  • 如果你有支援格式的字卡備份檔，請先用 字卡庫格式轉換器 轉成 DreamChat 字卡庫 JSON，再回到字卡庫選擇「匯入字卡庫」。目前支援 milk 老師字卡網站匯出的備份格式。
  • 在字卡組設定中填寫「適用情境」與「觸發關鍵字」，能幫助系統在收到訊息時挑到更合適的字卡組。
  • 想讓回覆更穩定，可把「隨機性」調低；想讓變化更多，可調高。

「智慧輔助」在角色設定的字卡庫區塊中設定，可選「關閉、自然、精準、多變」。它會依照收到的訊息、字卡組名稱、適用情境、觸發關鍵字與字卡內容選擇字卡組；Apple 語言處理可用時會加入裝置端判斷，但不會產生新的對話內容。想讓關鍵字更容易接對話題，可查看 智慧輔助設定技巧。

5. 設定角色語音訊息

路徑：角色 → 角色設定 → 語音訊息

  • 每則語音訊息需要短音檔、顯示文字與要套用的字卡組；啟用後會和同字卡組的文字字卡一起進入回覆候選。
  • 聊天抽到語音訊息時會送出可播放的語音泡泡；列表、搜尋、通知與文字匯出會使用顯示文字。
  • 語音容量會依目前方案與已購買的語音擴充包計算，超出容量的語音會封存，不會進入回覆候選。

完整設定、方案限制、語音包與備份差異請看 語音訊息詳細說明。

6. 用情境標籤指定目前對話脈絡

路徑：設定 → 情境 → 情境標籤

  • 先建立可重複使用的情境標籤，例如「睡前」、「旅行」、「安慰」。
  • 到自訂字卡組的設定中勾選適用的情境標籤，讓 DreamChat 知道這組字卡適合哪些情境。
  • 聊天時可從上方選單開啟「目前情境」，選擇此對話正在使用的情境標籤。
  • 「包含情境」會優先使用符合所選標籤的自訂字卡組；「排除情境」會避開符合所選標籤的字卡組。
  • 切換包含 / 排除模式時，另一個模式已選過的標籤會保留，不需要重新設定。

情境標籤適合用來快速切換「現在在聊什麼」，不是用來撰寫回覆內容。完整設定方式與影響範圍請看 情境標籤詳細說明。

7. 設定定時來訊

路徑：角色 → 角色設定 → 定時來訊

  1. 按加號新增定時來訊。
  2. 在「基本」設定名稱、來訊對話與是否啟用。
  3. 在「星期」選擇要觸發的日子。預設為每天，至少會保留一天。
  4. 在「時間」新增一個或多個來訊時間，也可以設定「時間浮動」。
  5. 在「來源」選擇手動輸入來訊內容，或從字卡庫隨機選擇。
  6. 如果手動輸入內容，請每一行放一則可能收到的訊息。

定時來訊需要通知權限。可到「設定 → 通知」開啟角色來訊通知，並在「設定 → 通知 → 系統權限」查看或調整通知狀態。

8. 天氣提醒

路徑：角色 → 角色設定 → 天氣提醒

  • 可為角色設定每日天氣提醒，選擇一對一聊天室、提醒時間、時間浮動與地區。
  • 手動選擇地區不需要定位權限；使用目前位置只會在你明確操作後請求「使用 App 期間」位置權限。
  • 開啟「在聊天中詢問」後，可用關鍵字讓角色回覆目前天氣，也可選擇命中時只送天氣回覆。

完整設定方式與字卡撰寫方式請看 天氣提醒詳細說明。

9. 視訊通話

路徑：角色 → 角色設定 → 視訊通話

  • 一對一聊天可撥打角色，或送出「讓他來電」請求。
  • 每個角色可設定是否啟用主動來電、來電頻率與通話背景；設定中的通知頁可調整響鈴與全域勿擾時段。
  • 這是本機模擬通話，不使用真實相機、麥克風或系統電話畫面；App 外只會跳本機通知。

來電邏輯、重撥與 App 外通知限制請看 視訊通話詳細說明。

10. 貼圖與表情符號

路徑：設定 → 貼圖與表情符號

  • 在「貼圖管理」新增貼圖組，進入貼圖組後可從相簿或檔案加入圖片。
  • 在「表情符號管理」整理可用的表情符號組。
  • 回到角色設定，進入「貼圖」選擇角色可使用的貼圖組，並調整使用頻率。
  • 聊天時按輸入列左側的表情按鈕，就能選擇貼圖或插入表情符號。

11. 系統權限

路徑：設定 → 通知 → 系統權限

  • 可查看通知、選取圖片、儲存截圖與 Music 資料庫狀態。
  • 只有在你按下「允許」或主動使用相關功能時才會請求權限。
  • 若權限已拒絕，DreamChat 會顯示「前往系統設定」，不會反覆跳出系統要求。

12. 設定、會員與備份

  • 「設定 → 自己」可修改自己的顯示名稱。
  • 「設定 → 會員」可查看目前方案、恢復購買與比較方案限制；符合資格時會顯示夢行者年方案一個月免費試用提示。
  • 「設定 → 外觀及語言」可切換主題顏色與 App 語言。
  • 「設定 → 資料」可匯出完整備份、角色設定文字檔、聊天記錄文字檔，也可以匯入完整備份。
  • 匯入完整備份會覆蓋目前 App 內資料，請先確認已保留需要的檔案。

想快速看本版新增功能，請看 3.1.0 版本更新內容。

DreamChat 使用说明

对应版本：v3.1.0

这份说明适合第一次使用 DreamChat 的用户。你可以先从聊天开始，再慢慢整理角色、字卡库、语音消息、定时来信与表情包。

快速开始 聊天 角色 字卡库 语音消息 情境标签 定时来信 天气提醒 视频通话 表情包 权限 设置与备份

1. 第一次打开 App

  1. DreamChat 会先建立一位默认角色与一个默认对话。
  2. 底部有三个主要分页：「角色」、「聊天」、「设置」。
  3. 想立刻开始，进入「聊天」分页，打开对话，在底部输入消息后按纸飞机发送。

角色的自动回复会从「字卡库」抽取。还没想好怎么设置时，可以先到 角色 → 角色设置 → 字卡库 → 导出／导入 → 应用预设模板 导入模板字卡库；如果只想先得到简短答案，也可以先使用 是否模式。

2. 聊天分页怎么用

「聊天」分页会列出最近对话。点进对话后，你可以：

  • 在底部输入文字并发送。
  • 按表情按钮打开表情包与表情符号。
  • 按放大镜搜索当前对话的消息，或按日期跳转。
  • 长按消息可回复、复制、截图或删除；截图预览可切换原始或匿名模式。
  • 上方菜单可切换「聊天模式」与「是否模式」，也可以使用「帮我选」。更多差异请看 聊天模式专栏。
  • 上方菜单也能打开角色设置、群组设置、当前情境，或暂停此对话的定时来信。
  • 一对一聊天可使用视频通话入口，或请角色稍后来电；聊天中也可用关键词询问当前天气。

如果想逐一认识聊天室工具栏、搜索、消息长按菜单、截图与输入栏，请看 聊天室画面导览。

3. 建立与管理角色

到「角色」分页，按右上角加号可以「新增角色」或「导入角色」。点进角色后可调整：

  • 角色名称、聊天室背景、是否显示已读与自己的头像。
  • 回复时间，例如最短与最长延迟。
  • 聊天模式：一般「聊天模式」或「是否模式」。
  • 字卡库、语音消息、表情包使用设置、定时来信、天气提醒与视频通话。
  • 右上角分享按钮可导出角色分享文件。

要新增对话，请到「聊天」分页按加号，选择「直接」或「群组」。群组对话至少需要两位可用角色，且必须是当前方案支持的功能。

4. 设置字卡库，让角色会回复

路径：角色 → 角色设置 → 字卡库

  • 「通用」是默认字卡组；你也可以新增自定义字卡组。
  • 进入字卡组后，按「新增回复字卡」，每行输入一张字卡。
  • 如果目前没有灵感，可以在字卡库页面右上角点「导出／导入」托盘图标，选择「应用预设模板」。接着选择模板语言（繁體中文、简体中文、日本語 或 English），再选择「追加」或「替换」。模板目前每种语言各有 260 张字卡。
  • 「追加」会保留当前字卡库并补入未重复内容；「替换」只会替换同名字卡组，没有匹配到的本机字卡组会保留。
  • 如果你有支持格式的字卡备份文件，请先用 字卡库格式转换器 转成 DreamChat 字卡库 JSON，再回到字卡库选择「导入字卡库」。目前支持 milk 老师字卡网站导出的备份格式。
  • 在字卡组设置中填写「适用情境」与「触发关键词」，能帮助系统在收到消息时挑到更合适的字卡组。
  • 想让回复更稳定，可把「随机性」调低；想让变化更多，可调高。

「智能辅助」在角色设置的字卡库区块中设置，可选「关闭、自然、精准、多变」。它会依据收到的消息、字卡组名称、适用情境、触发关键词与字卡内容选择字卡组；Apple 语言处理可用时会加入设备端判断，但不会生成新的对话内容。想让关键词更容易接对话题，可查看 智能辅助设置技巧。

5. 设置角色语音消息

路径：角色 → 角色设置 → 语音消息

  • 每条语音消息需要短音频、显示文字与要套用的字卡组；启用后会和同字卡组的文字字卡一起进入回复候选。
  • 聊天抽到语音消息时会发送可播放的语音气泡；列表、搜索、通知与文字导出会使用显示文字。
  • 语音容量会依当前方案与已购买的语音扩展包计算，超出容量的语音会封存，不会进入回复候选。

完整设置、方案限制、语音包与备份差异请看 语音消息详细说明。

6. 用情境标签指定当前对话脉络

路径：设置 → 情境 → 情境标签

  • 先建立可重复使用的情境标签，例如「睡前」、「旅行」、「安慰」。
  • 到自定义字卡组的设置中勾选适用的情境标签，让 DreamChat 知道这组字卡适合哪些情境。
  • 聊天时可从上方菜单打开「当前情境」，选择此对话正在使用的情境标签。
  • 「包含情境」会优先使用符合所选标签的自定义字卡组；「排除情境」会避开符合所选标签的字卡组。
  • 切换包含 / 排除模式时，另一个模式已选过的标签会保留，不需要重新设置。

情境标签适合用来快速切换「现在在聊什么」，不是用来撰写回复内容。完整设置方式与影响范围请看 情境标签详细说明。

7. 设置定时来信

路径：角色 → 角色设置 → 定时来信

  1. 按加号新增定时来信。
  2. 在「基本」设置名称、来信对话与是否启用。
  3. 在「星期」选择要触发的日子。默认为每天，至少会保留一天。
  4. 在「时间」新增一个或多个来信时间，也可以设置「时间浮动」。
  5. 在「来源」选择手动输入来信内容，或从字卡库随机选择。
  6. 如果手动输入内容，请每一行放一条可能收到的消息。

定时来信需要通知权限。可到「设置 → 通知」开启角色来信通知，并在「设置 → 通知 → 系统权限」查看或调整通知状态。

8. 天气提醒

路径：角色 → 角色设置 → 天气提醒

  • 可为角色设置每日天气提醒，选择一对一聊天室、提醒时间、时间浮动与地区。
  • 手动选择地区不需要定位权限；使用当前位置只会在你明确操作后请求「使用 App 期间」位置权限。
  • 开启「在聊天中询问」后，可用关键词让角色回复当前天气，也可选择命中时只发送天气回复。

完整设置方式与字卡撰写方式请看 天气提醒详细说明。

9. 视频通话

路径：角色 → 角色设置 → 视频通话

  • 一对一聊天可拨打角色，或发出「让他来电」请求。
  • 每个角色可设置是否启用主动来电、来电频率与通话背景；设置中的通知页可调整铃声与全局勿扰时段。
  • 这是本地模拟通话，不使用真实摄像头、麦克风或系统电话画面；App 外只会跳本地通知。

来电逻辑、重拨与 App 外通知限制请看 视频通话详细说明。

10. 表情包与表情符号

路径：设置 → 表情包与表情符号

  • 在「表情包管理」新增表情包组，进入表情包组后可从相册或文件加入图片。
  • 在「表情符号管理」整理可用的表情符号组。
  • 回到角色设置，进入「表情包」选择角色可使用的表情包组，并调整使用频率。
  • 聊天时按输入栏左侧的表情按钮，就能选择表情包或插入表情符号。

11. 系统权限

路径：设置 → 通知 → 系统权限

  • 可查看通知、图片选择、截图保存与 Music 资料库状态。
  • 只有在你点「允许」或主动使用相关功能时才会请求权限。
  • 若权限已拒绝，DreamChat 会显示「前往系统设置」，不会反复弹出系统请求。

12. 设置、会员与备份

  • 「设置 → 自己」可修改自己的显示名称。
  • 「设置 → 会员」可查看当前方案、恢复购买与比较方案限制；符合资格时会显示梦行者年方案一个月免费试用提示。
  • 「设置 → 外观及语言」可切换主题颜色与 App 语言。
  • 「设置 → 数据」可导出完整备份、角色设置文本、聊天记录文本，也可以导入完整备份。
  • 导入完整备份会覆盖当前 App 内数据，请先确认已保留需要的文件。

DreamChat 使い方ガイド

対応バージョン：v3.1.0

このガイドは、DreamChat を初めて使う方向けです。まずはチャットから始めて、必要に応じてキャラクター、定型文集、ボイスメッセージ、予約受信、スタンプを整えていけます。

はじめに チャット キャラクター 定型文集 ボイスメッセージ コンテキストタグ 予約受信 天気 ビデオ通話 スタンプ 権限 設定とバックアップ

1. 初回起動時

  1. DreamChat は、初回起動時に既定のキャラクターと既定の会話を作成します。
  2. 画面下部には「キャラクター」「チャット」「設定」の3つのタブがあります。
  3. すぐに始めるには、「チャット」タブで会話を開き、下部の入力欄にメッセージを入力して紙飛行機ボタンで送信します。

キャラクターの自動返信は「定型文集」から選ばれます。設定に迷うときは、先に キャラクター → キャラクター設定 → 定型文集 → 書き出し／読み込み → サンプルテンプレートを適用 からテンプレートを読み込めます。短い答えから始めたい場合は、はい/いいえモード も使えます。

2. チャットタブの使い方

「チャット」タブには最近の会話が表示されます。会話を開くと、次の操作ができます。

  • 下部の入力欄からメッセージを送信する。
  • 絵文字ボタンからスタンプと絵文字を開く。
  • 虫眼鏡ボタンで現在の会話内のメッセージを検索し、日付で移動する。
  • メッセージを長押しして、返信、コピー、スクリーンショット、削除を行う。スクリーンショットのプレビューではオリジナルまたは匿名を選べます。
  • 上部メニューで「チャットモード」と「はい/いいえモード」を切り替えたり、「選んで」を使ったりする。違いは チャットモードの記事 で確認できます。
  • 上部メニューからキャラクター設定、グループ設定、現在のコンテキスト、予約受信の一時停止を開く。
  • 1対1チャットではビデオ通話を開始したり、キャラクターにあとでかけてもらったりできます。キーワードで現在の天気を聞くこともできます。

チャットのツールバー、検索、長押しメニュー、スクリーンショット、入力欄を順番に確認したい場合は、チャット画面ガイドをご覧ください。

3. キャラクターの作成と管理

「キャラクター」タブで右上の追加ボタンを押すと、キャラクターの追加や読み込みができます。キャラクターを開くと、次の項目を設定できます。

  • キャラクター名、チャット背景、既読表示、自分のアイコン表示。
  • 返信タイミング、最小・最大の待ち時間。
  • チャットモード：通常の「チャットモード」または「はい/いいえモード」。
  • 定型文集、ボイスメッセージ、スタンプの使用設定、予約受信、天気リマインダー、ビデオ通話。
  • 右上の共有ボタンからキャラクター共有ファイルを書き出せます。

新しい会話を作るには、「チャット」タブで追加ボタンを押し、「直接」または「グループ」を選びます。グループ会話には利用可能なキャラクターが2人以上必要で、現在のプランで対応している必要があります。

4. 定型文集を設定して返信できるようにする

場所：キャラクター → キャラクター設定 → 定型文集

  • 「基本」は既定の定型文セットです。カスタム定型文セットも追加できます。
  • 定型文セットを開き、「定型文を追加」を押して、1行につき1件ずつ入力します。
  • 内容を作る手がかりがほしい場合は、定型文集画面の右上にある「書き出し／読み込み」のトレイアイコンを開き、「サンプルテンプレートを適用」を選びます。テンプレートの言語（繁體中文、简体中文、日本語、English）を選び、次に「追加」または「置き換え」を選びます。各言語のテンプレートには現在260件の定型文があります。
  • 「追加」は現在の定型文集を残して重複していない内容を追加します。「置き換え」は同じ名前のセットだけを置き換え、一致しない端末内のセットは残します。
  • 対応形式の定型文バックアップファイルがある場合は、先に 定型文集フォーマット変換ツール で DreamChat 定型文集 JSON に変換してから、定型文集で「定型文集を読み込む」を選びます。現在は milk の定型文サイトから書き出したバックアップ形式に対応しています。
  • 定型文セット設定で「使う場面」と「トリガーキーワード」を入力すると、受信メッセージに合う定型文セットを選びやすくなります。
  • 返信を安定させたい場合は「ランダム性」を低くし、変化を増やしたい場合は高くします。

「スマートアシスト」はキャラクター設定の定型文集セクションで設定でき、「オフ、自然、精密、多彩」から選べます。受信メッセージ、セット名、使う場面、トリガーキーワード、定型文の内容をもとに定型文セットを選びます。Apple の言語処理が利用できる場合は端末内の判断も使いますが、新しい会話文は生成しません。キーワードを合わせやすくするには、スマートアシスト設定のコツをご覧ください。

5. ボイスメッセージを設定する

場所：キャラクター → キャラクター設定 → ボイスメッセージ

  • 各ボイスメッセージには短い音声、表示テキスト、割り当てる定型文セットが必要です。有効にすると、同じ定型文セットのテキスト定型文と一緒に返信候補に入ります。
  • チャットで選ばれると、再生できる音声バブルとして送信されます。一覧、検索、通知、テキスト書き出しでは表示テキストが使われます。
  • ボイス容量は現在のプランと購入済みの追加パックで計算されます。容量を超えたボイスはアーカイブされ、返信候補には入りません。

詳しい設定、プラン制限、音声パッケージ、バックアップとの違いは ボイスメッセージ詳しい説明 をご覧ください。

6. コンテキストタグで今の会話の状況を指定する

場所：設定 → コンテキスト → コンテキストタグ

  • まず「寝る前」「旅行」「慰めてほしい」など、繰り返し使うコンテキストタグを作成します。
  • カスタム定型文セットの設定で、使う場面に合うコンテキストタグを選びます。
  • チャット中は上部メニューから「現在のコンテキスト」を開き、この会話で使うタグを選べます。
  • 「含めるコンテキスト」は選んだタグに合うカスタム定型文セットを優先します。「除外コンテキスト」は選んだタグに合うセットを避けます。
  • 含める / 除外を切り替えても、もう一方で選んだタグは残ります。

コンテキストタグは「今何について話しているか」を切り替えるためのもので、返信文そのものを書く機能ではありません。詳しい設定方法と影響範囲は コンテキストタグの詳しい説明 をご覧ください。

7. 予約受信を設定する

場所：キャラクター → キャラクター設定 → 予約受信

  1. 追加ボタンで予約受信を作成します。
  2. 「基本」で名前、受信する会話、有効状態を設定します。
  3. 「曜日」で受信する曜日を選びます。初期設定は毎日で、少なくとも1日は残ります。
  4. 「時間」で1つ以上の受信時刻を追加し、必要に応じて「時間のゆらぎ」を設定します。
  5. 「ソース」で、受信内容を手入力するか、定型文集からランダムに選ぶかを選択します。
  6. 手入力する場合は、1行につき1件のメッセージを入力します。

予約受信には通知の許可が必要です。「設定 → 通知」でキャラクターからの通知を有効にし、「設定 → 通知 → システム権限」で通知状態を確認または変更できます。

8. 天気リマインダー

場所：キャラクター → キャラクター設定 → 天気リマインダー

  • キャラクターごとに毎日の天気リマインダーを設定し、1対1チャット、時刻、時間のゆらぎ、地域を選べます。
  • 手動で地域を選ぶ場合は位置情報権限を使いません。現在地は明示的に選んだ後にだけ「App の使用中」の権限を求めます。
  • 「チャット内で質問」をオンにすると、キーワードで現在の天気に答えられます。

詳しい設定と定型文の書き方は 天気リマインダー詳しい説明をご覧ください。

9. ビデオ通話

場所：キャラクター → キャラクター設定 → ビデオ通話

  • 1対1チャットからキャラクターに発信したり、「あとでかけて」と依頼したりできます。
  • キャラクターごとに自発着信、着信頻度、通話背景を設定できます。通知設定では着信音と全体のサイレント時間を調整できます。
  • これはローカルの模擬通話です。実際のカメラ、マイク、システム電話画面は使わず、アプリ外ではローカル通知だけを表示します。

着信ロジック、再着信、アプリ外通知の制限は ビデオ通話詳しい説明をご覧ください。

10. スタンプと絵文字

場所：設定 → スタンプと絵文字

  • 「スタンプ管理」でスタンプセットを追加し、セット内で写真またはファイルから画像を追加します。
  • 「絵文字管理」で使用する絵文字セットを整理します。
  • キャラクター設定に戻り、「スタンプ」でそのキャラクターが使えるスタンプセットと使用頻度を選びます。
  • チャット中は入力欄左側の絵文字ボタンから、スタンプの送信や絵文字の挿入ができます。

11. システム権限

場所：設定 → 通知 → システム権限

  • 通知、画像選択、スクリーンショット保存、Music ライブラリの状態を確認できます。
  • 権限は、許可ボタンを押したとき、または関連機能を使ったときだけ求めます。
  • 拒否済みの場合、DreamChat はシステム設定への導線を表示し、同じ許可を繰り返し求めません。

12. 設定、メンバーシップ、バックアップ

  • 「設定 → 自分」で自分の表示名を変更できます。
  • 「設定 → メンバーシップ」で現在のプラン、購入の復元、プラン制限の比較を確認できます。対象ユーザーにはドリームウォーカー年間プランの1か月無料体験案内も表示されます。
  • 「設定 → 外観と言語」でテーマ色とアプリの言語を切り替えられます。
  • 「設定 → データ」では、完全バックアップ、キャラクター設定テキスト、チャット履歴テキストを書き出せます。完全バックアップの読み込みもできます。
  • 完全バックアップの読み込みは現在のアプリ内データを上書きします。必要なファイルを保存してから実行してください。

このバージョンの主な変更は、3.1.0 アップデート内容で確認できます。

DreamChat User Guide

Applies to version v3.1.0

This guide is for people opening DreamChat for the first time. Start with chat, then shape your characters, chat phrases, voice messages, scheduled messages, and stickers as you go.

Start Chat Characters Chat Phrases Voice Messages Context Tags Scheduled Messages Weather Video Calls Stickers Permissions Settings & Backup

1. First Launch

  1. DreamChat creates one default character and one default chat.
  2. The bottom tab bar has three main tabs: Characters, Chat, and Settings.
  3. To begin right away, open the Chat tab, enter the chat, type in the bottom input field, and tap the paper plane button.

Automatic character replies are chosen from Chat Phrases. If you are not sure how to set them up yet, open Characters → Character Settings → Chat Phrases → Export / Import → Apply Default Template to import the template library. For short answers first, you can also start with Yes/No Mode.

2. Using the Chat Tab

The Chat tab lists recent chats. Inside a chat, you can:

  • Type and send messages from the bottom input bar.
  • Tap the emoji button to open stickers and emoji.
  • Tap the search button to search messages in the current chat or jump by date.
  • Long-press a message to reply, copy, capture a screenshot, or delete it. Screenshot preview can switch between Original and Anonymous.
  • Use the top menu to switch between Chat Mode and Yes/No Mode, or use Choose for Me. See the Chat Modes article for the differences.
  • Use the top menu to open character settings, group settings, current context, or pause scheduled messages for this chat.
  • In one-on-one chats, you can start a Video Call or ask the character to call later. Weather keywords can also trigger current-weather replies.

For a tour of the chatroom toolbar, search, long-press menu, screenshots, and input bar, see the Chatroom Screen Guide.

3. Creating and Managing Characters

Open the Characters tab and tap the plus button to add or import a character. Open a character to adjust:

  • Character name, chat background, read receipts, and whether your own avatar is shown.
  • Reply timing, including minimum and maximum delay.
  • Chat mode: normal Chat Mode or Yes/No Mode.
  • Chat Phrases, Voice Messages, sticker usage, scheduled messages, Weather Reminder, and Video Call.
  • The share button in the top-right corner exports a character share file.

To create a new chat, open the Chat tab, tap the plus button, and choose Direct or Group. Group chats need at least two available characters and must be supported by your current plan.

4. Setting Up Chat Phrases for Replies

Path: Characters → Character Settings → Chat Phrases

  • General is the default phrase set. You can also create custom phrase sets.
  • Open a phrase set, tap Add Chat Phrases, and enter one chat phrase per line.
  • If you need a starting point, open the tray icon menu labeled Export / Import in the top-right corner of the Chat Phrases screen, then choose Apply Default Template. Choose a template language (繁體中文, 简体中文, 日本語, or English), then choose Append or Replace. Each language template currently contains 260 chat phrases.
  • Append keeps your current library and adds non-duplicate content. Replace updates matching phrase sets by name, while local sets without a match are kept.
  • If you have a supported phrase backup file, first use the Phrase Library Format Converter to create a DreamChat phrase library JSON, then return to Chat Phrases and choose Import Phrase Library. The converter currently supports the backup format exported from the milk phrase site.
  • In phrase set settings, add Usage Context and Trigger Keywords to help DreamChat pick the right set for incoming messages.
  • Lower Randomness for steadier replies; raise it for more variation.

Smart Assist is set in the Chat Phrases section of Character Settings, with Off, Natural, Precise, and Varied modes. It chooses a phrase set using the incoming message, set name, usage context, trigger keywords, and chat phrase text. When Apple language processing is available, on-device judgment can help, but it does not generate new conversation text. For better trigger keywords, see the Smart Assist setup tips.

5. Setting Up Character Voice Messages

Path: Characters → Character Settings → Voice Messages

  • Each voice message needs a short audio file, display text, and the phrase sets it should use. When enabled, it joins the reply pool with text phrases from the same phrase sets.
  • When a voice message is selected in chat, DreamChat sends a playable voice bubble. Lists, search, notifications, and text exports use the display text.
  • Voice capacity is calculated from your current plan and purchased Voice Expansion Packs. Voice messages beyond capacity are archived and do not enter the reply pool.

For full setup, plan limits, voice packages, and backup differences, see the Voice Messages Guide.

6. Using Context Tags for the Current Chat Context

Path: Settings → Context → Context Tags

  • Create reusable context tags such as "bedtime", "travel", or "comfort".
  • In a custom phrase set's settings, select the context tags that fit that set.
  • While chatting, open Current Context from the top menu and choose the tags for this conversation.
  • Include Context prioritizes custom phrase sets that match the selected tags. Exclude Context avoids phrase sets that match the selected tags.
  • Switching Include / Exclude keeps the tags selected in the other mode, so you do not need to set them again.

Context tags are for switching what the chat is currently about. They do not write reply text. For setup details and behavior notes, see the Context Tags guide.

7. Setting Up Scheduled Messages

Path: Characters → Character Settings → Scheduled messages

  1. Tap the plus button to add a scheduled message.
  2. In Basic, set the name, target chat, and enabled state.
  3. In Days, choose which days can send. The default is every day, and at least one day remains selected.
  4. In Time, add one or more times and optionally set Time variation.
  5. In Source, choose manual message content or random from Chat Phrase Library.
  6. If entering message content manually, put one possible message per line.

Scheduled messages need notification permission. You can enable Character Message Alerts in Settings → Notifications, and review the status in Settings → Notifications → System Permissions.

8. Weather Reminder

Path: Characters → Character Settings → Weather Reminder

  • Set a daily weather reminder for a character, including the target one-on-one chat, reminder time, time variation, and region.
  • Manual region selection does not require location permission. Current location is requested only after you explicitly choose to use it.
  • When Ask in Chat is enabled, keywords can trigger current-weather replies, with an option to send only the weather reply.

For full setup and phrase-writing guidance, see the Weather Reminder Guide.

9. Video Call

Path: Characters → Character Settings → Video Call

  • In one-on-one chats, you can call a character or ask them to call later.
  • Each character can control incoming calls, frequency, and call background. Notification settings control ringtone and global quiet hours.
  • This is a local simulated call. It does not use the real camera, microphone, or system phone UI. Outside the app, it only shows local notifications.

For incoming-call logic, redials, and outside-app notification limits, see the Video Call Guide.

10. Stickers and Emoji

Path: Settings → Stickers & Emoji

  • In Sticker Management, create a sticker set, then add images from Photos or Files.
  • In Emoji Management, organize the emoji sets you want to use.
  • Return to Character Settings, open Stickers, choose which sticker sets the character can use, and adjust Frequency.
  • In chat, tap the emoji button on the left side of the input bar to send stickers or insert emoji.

11. System Permissions

Path: Settings → Notifications → System Permissions

  • Review notifications, photo selection, screenshot saving, and Music library access.
  • DreamChat asks only when you tap Allow or use a related feature.
  • If access was denied, DreamChat shows Open Settings instead of repeatedly asking again.

12. Settings, Membership, and Backup

  • Settings → Me lets you change your display name.
  • Settings → Membership shows your current plan, Restore Purchases, and plan limit comparison. Eligible users also see the one-month Dream Walker yearly trial prompt.
  • Settings → Appearance & Language changes the theme color and app language.
  • Settings → Data can export a full backup, character settings text, or chat history text, and can import a full backup.
  • Importing a full backup overwrites the current app data. Keep any files you need before continuing.
