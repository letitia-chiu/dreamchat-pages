情境標籤詳細說明

對應版本：v3.0.0

情境標籤是 DreamChat 用來標記「現在這段對話在什麼情境中」的輔助工具。它不會產生新的回覆文字，而是協助 App 從更合適的字卡組中選回覆。

用途 建立與管理 套用到字卡組 設定目前情境 包含 / 排除 回覆選擇 備份與匯入

1. 情境標籤是什麼

你可以把情境標籤想成跨角色共用的短標籤，例如「睡前」、「旅行」、「吃醋」、「需要安慰」。標籤本身不是字卡，也不是觸發關鍵字；它主要用來連接「目前聊天情境」與「適合這個情境的字卡組」。

  • 情境標籤在設定中建立後，可被多個角色與多個字卡組使用。
  • 每個標籤名稱最多 24 個字，最多可建立 200 個情境標籤。
  • 同一次選擇中最多可勾選 8 個情境標籤。

2. 建立與管理情境標籤

路徑：設定 → 情境 → 情境標籤

  1. 按右上角加號新增情境標籤。
  2. 輸入名稱後儲存。名稱不可空白，也不可和既有標籤重複。
  3. 點選既有標籤可編輯名稱；在列表中滑動可刪除。

刪除情境標籤後，這個標籤會從所有字卡組與聊天室目前情境中移除。

3. 套用到字卡組

路徑：角色 → 角色設定 → 字卡庫 → 自訂字卡組 → 字卡組設定 → 情境標籤

在自訂字卡組設定中，除了「適用情境」與「觸發關鍵字」，也可以選擇情境標籤。這代表這組字卡適合在那些情境中被選到。

  • 一個字卡組可以有多個情境標籤。
  • 同一個情境標籤也可以套用在多個字卡組。
  • 「通用」字卡組不需要設定情境標籤，會保留為可用的基本回覆來源。

4. 在聊天室設定目前情境

路徑：聊天 → 開啟對話 → 上方選單 → 目前情境

目前情境是針對單一聊天室保存的脈絡。你可以在聊天途中選擇一個或多個情境標籤，並決定要「包含情境」或「排除情境」。

  • 上方區塊會顯示已選標籤；點選已選標籤可移除。
  • 下方區塊會顯示尚未選取的候選標籤；點選可加入目前情境。
  • 沒有選任何標籤時，聊天室會顯示為沒有指定情境。
  • 切換包含 / 排除模式時，另一個模式下已選過的標籤會保留下來。

5. 包含情境與排除情境

v3.0.0 起，聊天室目前情境有兩種模式：

  • 包含情境：角色回覆會優先從符合所選情境標籤的字卡組中選擇。
  • 排除情境：角色回覆會避開符合所選情境標籤的字卡組。
  • 兩種模式各自保存已選標籤，切換模式不會清掉另一邊的選擇。

6. 它怎麼影響回覆選擇

情境標籤只影響字卡選擇，不會改寫字卡內容，也不會讓智慧輔助產生新的對話文字。

  • 沒有指定目前情境時，DreamChat 會照一般字卡庫與智慧輔助規則選擇字卡組。
  • 包含情境時，符合任一已選標籤的自訂字卡組會成為候選；排除情境時，符合任一已選標籤的字卡組會被避開。
  • 通用字卡組仍會保留為可用來源，適合放不限定情境的基本回覆。
  • 如果目前情境沒有對應的自訂字卡組，回覆可能會改從通用字卡組選出；若沒有可用字卡，角色就不會自動回覆。

7. 備份、匯出與匯入

完整備份會還原備份中的情境標籤與關聯。角色分享檔與字卡庫匯入匯出也會保留情境標籤與字卡組的關聯；匯入時，若本機已有同名標籤，DreamChat 會接到既有標籤，沒有同名標籤時才新增。

如果你從外部整理字卡庫，建議先把情境標籤命名想清楚，再套用到字卡組。標籤越穩定，之後匯入與整理越不容易混亂。

情境标签详细说明

对应版本：v3.0.0

情境标签是 DreamChat 用来标记「现在这段对话在什么情境中」的辅助工具。它不会生成新的回复文字，而是协助 App 从更合适的字卡组中选择回复。

用途 建立与管理 套用到字卡组 设置当前情境 包含 / 排除 回复选择 备份与导入

1. 情境标签是什么

你可以把情境标签想成跨角色共用的短标签，例如「睡前」、「旅行」、「吃醋」、「需要安慰」。标签本身不是字卡，也不是触发关键词；它主要用来连接「当前聊天情境」与「适合这个情境的字卡组」。

  • 情境标签在设置中建立后，可被多个角色与多个字卡组使用。
  • 每个标签名称最多 24 个字，最多可建立 200 个情境标签。
  • 同一次选择中最多可勾选 8 个情境标签。

2. 建立与管理情境标签

路径：设置 → 情境 → 情境标签

  1. 按右上角加号新增情境标签。
  2. 输入名称后保存。名称不可为空，也不可和已有标签重复。
  3. 点选已有标签可编辑名称；在列表中滑动可删除。

删除情境标签后，这个标签会从所有字卡组与聊天室当前情境中移除。

3. 套用到字卡组

路径：角色 → 角色设置 → 字卡库 → 自定义字卡组 → 字卡组设置 → 情境标签

在自定义字卡组设置中，除了「适用情境」与「触发关键词」，也可以选择情境标签。这代表这组字卡适合在那些情境中被选到。

  • 一个字卡组可以有多个情境标签。
  • 同一个情境标签也可以套用在多个字卡组。
  • 「通用」字卡组不需要设置情境标签，会保留为可用的基本回复来源。

4. 在聊天室设置当前情境

路径：聊天 → 打开对话 → 上方菜单 → 当前情境

当前情境是针对单一聊天室保存的脉络。你可以在聊天途中选择一个或多个情境标签，并决定要「包含情境」或「排除情境」。

  • 上方区块会显示已选标签；点选已选标签可移除。
  • 下方区块会显示尚未选取的候选标签；点选可加入当前情境。
  • 没有选任何标签时，聊天室会显示为没有指定情境。
  • 切换包含 / 排除模式时，另一个模式下已选过的标签会保留下来。

5. 包含情境与排除情境

v3.0.0 起，聊天室当前情境有两种模式：

  • 包含情境：角色回复会优先从符合所选情境标签的字卡组中选择。
  • 排除情境：角色回复会避开符合所选情境标签的字卡组。
  • 两种模式各自保存已选标签，切换模式不会清掉另一边的选择。

6. 它如何影响回复选择

情境标签只影响字卡选择，不会改写字卡内容，也不会让智能辅助生成新的对话文字。

  • 没有指定当前情境时，DreamChat 会按一般字卡库与智能辅助规则选择字卡组。
  • 包含情境时，符合任一已选标签的自定义字卡组会成为候选；排除情境时，符合任一已选标签的字卡组会被避开。
  • 通用字卡组仍会保留为可用来源，适合放不限定情境的基本回复。
  • 如果当前情境没有对应的自定义字卡组，回复可能会改从通用字卡组选出；若没有可用字卡，角色就不会自动回复。

7. 备份、导出与导入

完整备份会还原备份中的情境标签与关联。角色分享文件与字卡库导入导出也会保留情境标签与字卡组的关联；导入时，若本机已有同名标签，DreamChat 会接到已有标签，没有同名标签时才新增。

如果你从外部整理字卡库，建议先把情境标签命名想清楚，再套用到字卡组。标签越稳定，之后导入与整理越不容易混乱。

コンテキストタグの詳しい説明

対応バージョン：v3.0.0

コンテキストタグは、「今の会話がどの状況にあるか」を DreamChat に伝えるための補助機能です。新しい返信文を生成するものではなく、より合う定型文セットから返信を選びやすくします。

用途 作成と管理 定型文セットに設定 現在のコンテキスト 含める / 除外 返信選択 バックアップ

1. コンテキストタグとは

コンテキストタグは、キャラクターをまたいで使える短いタグです。たとえば「寝る前」「旅行」「嫉妬」「慰めてほしい」などを作れます。タグ自体は定型文でもトリガーキーワードでもなく、「現在のチャット状況」と「その状況に合う定型文セット」をつなぐために使います。

  • 設定で作成したタグは、複数のキャラクターや定型文セットで使えます。
  • タグ名は最大 24 文字、作成できるタグは最大 200 個です。
  • 一度に選べるコンテキストタグは最大 8 個です。

2. コンテキストタグを作成・管理する

場所：設定 → コンテキスト → コンテキストタグ

  1. 右上の追加ボタンでコンテキストタグを作成します。
  2. 名前を入力して保存します。空の名前や、既存タグと同じ名前は使えません。
  3. 既存タグをタップすると名前を編集できます。リストでスワイプすると削除できます。

タグを削除すると、すべての定型文セットとチャットの現在のコンテキストから外れます。

3. 定型文セットに設定する

場所：キャラクター → キャラクター設定 → 定型文集 → カスタム定型文セット → 定型文セット設定 → コンテキストタグ

カスタム定型文セットの設定では、「使う場面」と「トリガーキーワード」に加えて、コンテキストタグも選べます。これは、その定型文セットがどの状況に合うかを示します。

  • 1つの定型文セットに複数のタグを付けられます。
  • 同じタグを複数の定型文セットに使うこともできます。
  • 基本の定型文セットにはタグ設定は不要で、基本的な返信元として残ります。

4. チャットで現在のコンテキストを設定する

場所：チャット → 会話を開く → 上部メニュー → 現在のコンテキスト

現在のコンテキストは、1つのチャットごとに保存される状況指定です。会話中に1つ以上のタグを選び、「含めるコンテキスト」または「除外コンテキスト」を選択できます。

  • 上の欄には選択済みタグが表示され、タップすると外せます。
  • 下の欄には未選択の候補タグが表示され、タップすると追加できます。
  • 何も選んでいない場合は、指定なしのコンテキストとして扱われます。
  • 含める / 除外を切り替えても、もう一方で選んだタグは残ります。

5. 含めるコンテキストと除外コンテキスト

v3.0.0 から、チャットの現在のコンテキストには2つのモードがあります。

  • 含めるコンテキスト：選んだタグに合う定型文セットが優先されます。
  • 除外コンテキスト：選んだタグに合う定型文セットを避けます。
  • 2つのモードはそれぞれ選択タグを保存し、切り替えてももう一方の選択は消えません。

6. 返信選択への影響

コンテキストタグは定型文の選択にだけ影響します。定型文の内容を書き換えたり、スマートアシストに新しい会話文を生成させたりするものではありません。

  • 現在のコンテキストが未指定の場合、通常の定型文集とスマートアシストのルールで選ばれます。
  • 含めるコンテキストでは、選んだタグに一致するカスタム定型文セットが候補になります。除外コンテキストでは、選んだタグに一致するセットを避けます。
  • 基本の定型文セットは引き続き使用できます。状況を限定しない基本返信を入れておくのに向いています。
  • 現在のコンテキストに一致するカスタムセットがない場合は、基本セットから返信が選ばれることがあります。使える定型文がなければ、自動返信は行われません。

7. バックアップ、書き出し、読み込み

完全バックアップでは、バックアップ内のコンテキストタグと関連が復元されます。キャラクター共有ファイルや定型文集の読み込み・書き出しでも、コンテキストタグと定型文セットの関連は保持されます。読み込み時に同名タグがすでにある場合は既存タグに接続され、ない場合だけ新しいタグが追加されます。

外部で定型文集を整理する場合は、先にタグ名を決めてから定型文セットに付けると、後から読み込むときも整理しやすくなります。

Context Tags Guide

Applies to version v3.0.0

Context tags help DreamChat understand what this chat is currently about. They do not generate new reply text; they help the app choose replies from better-fitting phrase sets.

Purpose Create & Manage Phrase Sets Current Context Include / Exclude Reply Selection Import & Backup

1. What Context Tags Are

Think of context tags as short shared labels, such as "bedtime", "travel", "jealousy", or "comfort". A tag is not a phrase and not a trigger keyword. It connects the current chat context with phrase sets that fit that context.

  • Tags created in Settings can be reused across characters and phrase sets.
  • Each tag name can be up to 24 characters, and you can create up to 200 context tags.
  • You can select up to 8 context tags in one selection area.

2. Create and Manage Context Tags

Path: Settings → Context → Context Tags

  1. Tap the plus button in the top-right corner to create a context tag.
  2. Enter a name and save. The name cannot be empty or duplicate an existing tag.
  3. Tap an existing tag to rename it. Swipe in the list to delete it.

Deleting a context tag removes it from all phrase sets and from every chat's current context.

3. Assign Tags to Phrase Sets

Path: Characters → Character Settings → Chat Phrases → Custom Phrase Set → Phrase Set Settings → Context Tags

In custom phrase set settings, you can choose context tags alongside Usage Context and Trigger Keywords. This marks which situations the phrase set fits.

  • One phrase set can have multiple context tags.
  • The same context tag can be used by multiple phrase sets.
  • The General phrase set does not need context tags and remains available as a basic reply source.

4. Set the Current Context in a Chat

Path: Chat → Open a conversation → Top menu → Current Context

The current context is saved per chat. While chatting, select one or more tags and choose Include Context or Exclude Context.

  • The top section shows selected tags. Tap a selected tag to remove it.
  • The lower section shows available tags that are not selected. Tap one to add it.
  • When no tags are selected, the chat has no specified context.
  • Switching Include / Exclude keeps the tags selected in the other mode.

5. Include Context and Exclude Context

Starting in v3.0.0, the current chat context has two modes:

  • Include Context: replies prioritize phrase sets matching the selected context tags.
  • Exclude Context: replies avoid phrase sets matching the selected context tags.
  • Each mode keeps its own selected tags, so switching modes does not clear the other selection.

6. How Tags Affect Reply Selection

Context tags only affect phrase selection. They do not rewrite phrase text or make Smart Assist generate new conversation text.

  • When no current context is selected, DreamChat uses the usual phrase library and Smart Assist rules.
  • In Include Context, custom phrase sets matching any selected tag become candidates. In Exclude Context, phrase sets matching selected tags are avoided.
  • The General phrase set remains available, which makes it a good place for replies that are not tied to a specific situation.
  • If the current context has no matching custom phrase set, DreamChat may choose from General instead. If no usable phrases exist, the character will not auto-reply.

7. Backup, Export, and Import

Full backup restores the context tags and links stored in that backup. Character share files and phrase library import/export also preserve context tags and their phrase set links. During import, DreamChat connects to an existing local tag when the name already matches; otherwise it creates a new tag.

If you organize a phrase library outside the app, decide stable context tag names first, then apply them to phrase sets. Stable names make future imports easier to understand.
