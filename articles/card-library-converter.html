字卡庫格式轉換器

將支援的字卡備份 JSON 轉成 DreamChat 可用的「匯入字卡庫」格式。檔案只會在你的瀏覽器中讀取，不會上傳。

轉換後怎麼匯入

  1. 選擇支援格式的字卡備份 JSON。
  2. 下載轉換後的 DreamChat 字卡庫 JSON。
  3. 在 DreamChat 開啟「角色 → 角色設定 → 字卡庫」，從右上角選單選擇「匯入字卡庫」。

目前支援 milk 老師字卡網站匯出的備份格式。若要從該網站匯出備份檔，請依序開啟「设置 → 高级功能 → 自定义回复 → 回复库管理 → 导出」。此工具不是 milk 老師網站的官方功能，只協助將使用者自行匯出的備份檔轉成 DreamChat 可匯入格式。

customReplies 會轉成通用字卡組，customReplyGroups 會轉成自訂字卡組。

字卡库格式转换器

将支持的字卡备份 JSON 转成 DreamChat 可用于「导入字卡库」的格式。文件只会在你的浏览器中读取，不会上传。

转换后如何导入

  1. 选择支持格式的字卡备份 JSON。
  2. 下载转换后的 DreamChat 字卡库 JSON。
  3. 在 DreamChat 打开「角色 → 角色设置 → 字卡库」，从右上角菜单选择「导入字卡库」。

目前支持 milk 老师字卡网站导出的备份格式。若要从该网站导出备份文件，请依次打开「设置 → 高级功能 → 自定义回复 → 回复库管理 → 导出」。此工具不是 milk 老师网站的官方功能，只协助将用户自行导出的备份文件转成 DreamChat 可导入格式。

customReplies 会转成通用字卡组，customReplyGroups 会转成自定义字卡组。

定型文集フォーマット変換ツール

対応している定型文バックアップ JSON を、DreamChat の「定型文集を読み込む」で使える形式に変換します。ファイルはブラウザ内でのみ読み取られ、アップロードされません。

変換後の読み込み手順

  1. 対応形式の定型文バックアップ JSON を選びます。
  2. 変換後の DreamChat 定型文集 JSON をダウンロードします。
  3. DreamChat で「キャラクター → キャラクター設定 → 定型文集」を開き、右上メニューから「定型文集を読み込む」を選びます。

現在は、milk の定型文サイトから書き出したバックアップ形式に対応しています。milk のサイトでバックアップを書き出すには「设置 → 高级功能 → 自定义回复 → 回复库管理 → 导出」を開いてください。このツールは milk 公式の機能ではなく、ユーザーが自分で書き出したバックアップファイルを DreamChat で読み込める形式に変換するためのものです。

customReplies は基本の定型文セット、customReplyGroups はカスタム定型文セットに変換されます。

Phrase Library Format Converter

Convert supported phrase backup JSON files into the DreamChat Import Phrase Library format. The file is read only in your browser and is not uploaded.

How to import the converted file

  1. Choose a supported phrase backup JSON file.
  2. Download the converted DreamChat phrase library JSON.
  3. In DreamChat, open Characters → Character Settings → Chat Phrases, then choose Import Phrase Library from the top-right menu.

This currently supports the backup format exported from the milk phrase site. To export that backup from the milk site, open 「设置 → 高级功能 → 自定义回复 → 回复库管理 → 导出」. This is not an official milk feature; it only helps convert backup files that users export themselves into a format DreamChat can import.

customReplies becomes the General phrase set, and customReplyGroups becomes custom phrase groups.
