聊天室畫面導覽

對應版本：v2.9.0

打開對話後，聊天室主要分成上方工具列、訊息區、搜尋列、截圖選取列與底部輸入列。這篇說明每個入口可以做什麼。

上方工具列 聊天選單 搜尋 訊息操作 輸入列 音樂播放器

1. 上方工具列

  • 返回：回到聊天列表，聊天室會保存目前對話狀態。
  • 音樂按鈕：可開啟播放器、選擇播放清單，或使用推薦播放清單。
  • 搜尋：開啟目前聊天室的訊息搜尋列。
  • 模式按鈕：依目前模式顯示聊天或是否圖示，點開可進入更多聊天室選單。

2. 右上角聊天選單

  • 聊天模式：切換「聊天模式」或「是否模式」。
  • 幫我選：輸入題目與至少兩個選項，讓角色從選項中回覆一個。
  • 角色設定或群組設定：一對一聊天會開啟角色設定；群組聊天會開啟群組成員與群組資訊。
  • 目前情境：選擇這個對話正在使用的情境標籤，影響字卡組挑選。
  • 暫停定時來訊：暫停或恢復此對話的定時來訊。

3. 搜尋列與日期跳轉

按放大鏡後可搜尋目前聊天室中的訊息。輸入關鍵字後，搜尋列會顯示目前第幾筆結果，並可用上下箭頭切換前後結果。

  • 訊息泡泡按鈕：打開結果列表，可載入更舊結果並點選跳轉。
  • 日曆按鈕：依日期跳到有訊息的日子。
  • 關閉按鈕：離開搜尋列，回到一般聊天畫面。

4. 訊息長按操作

長按訊息可開啟操作選單。iOS 18 若系統原生選單不穩定，DreamChat 會改用底部選單顯示同樣的主要操作。

  • 回覆：可引用對方訊息，輸入列上方會顯示正在回覆誰；自己的訊息與系統訊息不會提供回覆。
  • 複製：把訊息文字複製到剪貼簿。
  • 截圖：進入截圖選取模式，先選起點再選終點，確認後可在預覽中切換原始或匿名。
  • 刪除：刪除該則訊息，刪除前會再次確認。

匿名截圖會替換參與者名稱與頭像後再儲存或分享。貼圖本身仍會保留在截圖中，因此分享前請確認畫面內容。

5. 底部輸入列

  • 表情按鈕：開啟貼圖與表情符號，選擇貼圖會直接送出，選擇表情符號會插入文字欄。
  • 文字欄：輸入訊息；群組聊天輸入 @ 時會出現可提及的角色建議。
  • 紙飛機：送出文字訊息；空白訊息或目前方案不可用時無法送出。
  • 回覆預覽：回覆訊息時會出現在輸入列上方，可按叉號取消。

6. 浮動音樂播放器

有可用佇列時，聊天室會顯示浮動播放器。小播放器可播放/暫停、開啟佇列、展開或收起；展開後可上一首、下一首、拖曳進度、隨機播放或切換重複播放。

聊天室画面导览

对应版本：v2.9.0

打开对话后，聊天室主要分成上方工具栏、消息区、搜索栏、截图选择栏与底部输入栏。这篇说明每个入口可以做什么。

上方工具栏 聊天菜单 搜索 消息操作 输入栏 音乐播放器

1. 上方工具栏

  • 返回：回到聊天列表，聊天室会保存当前对话状态。
  • 音乐按钮：可打开播放器、选择播放列表，或使用推荐播放列表。
  • 搜索：打开当前聊天室的消息搜索栏。
  • 模式按钮：依当前模式显示聊天或是否图标，点开可进入更多聊天室菜单。

2. 右上角聊天菜单

  • 聊天模式：切换「聊天模式」或「是否模式」。
  • 帮我选：输入题目与至少两个选项，让角色从选项中回复一个。
  • 角色设置或群组设置：一对一聊天会打开角色设置；群组聊天会打开群组成员与群组信息。
  • 当前情境：选择这个对话正在使用的情境标签，影响字卡组挑选。
  • 暂停定时来信：暂停或恢复此对话的定时来信。

3. 搜索栏与日期跳转

点放大镜后可搜索当前聊天室中的消息。输入关键词后，搜索栏会显示当前第几条结果，并可用上下箭头切换前后结果。

  • 消息气泡按钮：打开结果列表，可加载更旧结果并点选跳转。
  • 日历按钮：按日期跳到有消息的日子。
  • 关闭按钮：离开搜索栏，回到一般聊天画面。

4. 消息长按操作

长按消息可打开操作菜单。iOS 18 若系统原生菜单不稳定，DreamChat 会改用底部菜单显示同样的主要操作。

  • 回复：可引用对方消息，输入栏上方会显示正在回复谁；自己的消息与系统消息不会提供回复。
  • 复制：把消息文字复制到剪贴板。
  • 截图：进入截图选择模式，先选起点再选终点，确认后可在预览中切换原始或匿名。
  • 删除：删除该条消息，删除前会再次确认。

匿名截图会替换参与者名称与头像后再保存或分享。表情包图片本身仍会保留在截图中，因此分享前请确认画面内容。

5. 底部输入栏

  • 表情按钮：打开表情包与表情符号，选择表情包会直接发送，选择表情符号会插入文字栏。
  • 文字栏：输入消息；群组聊天输入 @ 时会出现可提及的角色建议。
  • 纸飞机：发送文字消息；空白消息或当前方案不可用时无法发送。
  • 回复预览：回复消息时会出现在输入栏上方，可点叉号取消。

6. 浮动音乐播放器

有可用队列时，聊天室会显示浮动播放器。小播放器可播放/暂停、打开队列、展开或收起；展开后可上一首、下一首、拖动进度、随机播放或切换重复播放。

チャット画面ガイド

対応バージョン：v2.9.0

会話を開くと、画面は主に上部ツールバー、メッセージエリア、検索バー、スクリーンショット選択バー、下部入力欄に分かれています。それぞれの操作を確認できます。

上部ツールバー チャットメニュー 検索 メッセージ操作 入力欄 音楽プレイヤー

1. 上部ツールバー

  • 戻る：チャット一覧に戻ります。会話の状態は保持されます。
  • 音楽ボタン：プレイヤーを開く、プレイリストを選ぶ、またはおすすめプレイリストを使えます。
  • 検索：現在のチャット内のメッセージ検索バーを開きます。
  • モードボタン：現在のモードに合わせてチャットまたははい/いいえのアイコンを表示し、タップするとチャットメニューを開きます。

2. 右上のチャットメニュー

  • チャットモード：「チャットモード」と「はい/いいえモード」を切り替えます。
  • 選んで：質問と2つ以上の選択肢を入力し、キャラクターに1つ選ばせます。
  • キャラクター設定またはグループ設定：1対1ではキャラクター設定、グループではメンバーとグループ情報を開きます。
  • 現在のコンテキスト：この会話で使うコンテキストタグを選び、定型文セットの選択に反映します。
  • 予約受信を一時停止：この会話の予約受信を一時停止または再開します。

3. 検索バーと日付移動

虫眼鏡を押すと、現在のチャット内を検索できます。キーワードを入力すると、現在の結果番号が表示され、上下ボタンで前後の結果へ移動できます。

  • 吹き出しボタン：結果一覧を開き、古い結果をさらに読み込んだり、選んで移動したりできます。
  • カレンダーボタン：メッセージがある日付へ移動できます。
  • 閉じるボタン：検索バーを閉じ、通常のチャット画面に戻ります。

4. メッセージの長押し操作

メッセージを長押しすると操作メニューが開きます。iOS 18 でシステムのメニューが不安定な場合は、DreamChat が下部メニューで同じ主要操作を表示します。

  • 返信：相手のメッセージを引用できます。入力欄の上に返信先が表示されます。自分のメッセージとシステムメッセージには表示されません。
  • コピー：メッセージ本文をクリップボードにコピーします。
  • スクリーンショット：選択モードに入り、開始メッセージと終了メッセージを選びます。確認後、プレビューでオリジナルまたは匿名を選べます。
  • 削除：そのメッセージを削除します。削除前に確認があります。

匿名スクリーンショットでは参加者名とアイコンを置き換えてから保存または共有します。スタンプ画像自体は残るため、共有前に内容を確認してください。

5. 下部入力欄

  • 絵文字ボタン：スタンプと絵文字を開きます。スタンプは直接送信され、絵文字は入力欄に挿入されます。
  • テキスト欄：メッセージを入力します。グループチャットで @ を入力すると、メンション候補が表示されます。
  • 紙飛行機ボタン：文字メッセージを送信します。空白、または現在のプランで利用できない状態では送信できません。
  • 返信プレビュー：返信中は入力欄の上に表示され、閉じるボタンでキャンセルできます。

6. フローティング音楽プレイヤー

利用できるキューがある場合、チャット画面にフローティングプレイヤーが表示されます。小さい表示では再生/一時停止、キュー表示、展開、折りたたみができ、展開すると前後の曲、シーク、シャッフル、リピートも操作できます。

Chatroom Screen Guide

Applies to version v2.9.0

Inside a conversation, the chatroom is organized around the top toolbar, message area, search bar, screenshot selection bar, and bottom input bar. This guide explains what each entry point does.

Top Toolbar Chat Menu Search Message Actions Input Bar Music Player

1. Top Toolbar

  • Back returns to the chat list while keeping the conversation state.
  • The music button opens the player, lets you select a playlist, or starts a recommended playlist.
  • Search opens message search for the current chat.
  • The mode button shows the current Chat or Yes/No icon and opens the broader chat menu.

2. Top-Right Chat Menu

  • Chat Mode switches between Chat Mode and Yes/No Mode.
  • Choose for Me lets you enter a question and at least two options, then the character replies with one option.
  • Character Settings or Group Settings opens character settings in direct chats, or group members and group info in group chats.
  • Current Context chooses context tags for this conversation and affects phrase set selection.
  • Pause Scheduled Messages pauses or resumes scheduled messages for this conversation.

3. Search Bar and Date Jump

Tap the magnifying glass to search messages in the current chat. After you enter a keyword, the search bar shows the selected result count and lets you move with up and down buttons.

  • The message bubble button opens the result list, where you can load older results and jump to one.
  • The calendar button jumps by date to days that have messages.
  • The close button exits search and returns to the normal chat view.

4. Long-Press Message Actions

Long-press a message to open actions. On iOS 18, if the native system menu is unreliable, DreamChat presents the same main actions in a bottom action sheet.

  • Reply quotes a partner message and shows the reply target above the input bar. Your own messages and system messages do not offer Reply.
  • Copy copies the message text to the clipboard.
  • Screenshot starts range selection. Choose a start and end message, then confirm and switch between Original and Anonymous in the preview.
  • Delete removes the message after a confirmation.

Anonymous screenshots replace participant names and avatars before saving or sharing. Sticker images remain visible, so review the preview before sharing.

5. Bottom Input Bar

  • The emoji button opens stickers and emoji. Stickers send directly; emoji are inserted into the text field.
  • The text field sends messages. In group chats, typing @ shows mention suggestions.
  • The paper plane sends text. Empty messages and unavailable plan states cannot be sent.
  • The reply preview appears above the input bar while replying and can be canceled with the close button.

6. Floating Music Player

When a usable queue exists, the chatroom can show a floating player. The small player can play or pause, open the queue, expand, or collapse. Expanded controls include previous, next, seeking, shuffle, and repeat.
