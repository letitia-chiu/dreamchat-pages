視訊通話詳細說明

新功能

對應版本：v3.0.0

視訊通話是 DreamChat 內的本機模擬互動，用來呈現角色來電、通話浮窗與通話事件。它不會開啟真實相機或麥克風，也不是實際電話或網路影音通話。

設定方式撥打與來電主動來電App 外通知通話背景

1. 開啟角色視訊通話

路徑：角色 → 角色設定 → 視訊通話

  1. 開啟角色的視訊通話功能。
  2. 需要角色主動來電時，開啟主動來電並選擇頻率。
  3. 到「設定 → 通知」調整視訊通話響鈴與全域勿擾時段。
  4. 設定通話背景。免費版可用靜態圖片，升級方案可用靜態圖片與短影片背景。

2. 使用者撥打與「讓他來電」

一對一聊天室可撥打角色；群組聊天第一版不顯示視訊通話入口。你也可以送出「讓他來電」請求，系統會依角色回應與本機排程決定是否安排一次來電。

接通、未接、拒接、逾時或使用者取消，都會在聊天紀錄中留下通話事件，方便回顧對話脈絡。

3. 角色主動來電邏輯

角色可設定很少、普通、頻繁或不固定等頻率。候選時間到達後，系統會用自然延遲建立來電；接聽期限約 60 秒。一般主動來電未接、拒接或逾時後，約 30 到 60 分鐘後可能安排一次重撥，重撥仍未接後才回到原本頻率。

4. App 外不會像真實電話般響鈴

DreamChat 不使用 CallKit、PushKit、VoIP push 或系統電話畫面。App 在背景或不適合顯示來電介面時，只會跳本機來電通知；不會像真實電話一樣持續全螢幕響鈴。

5. 通話背景與通話中切換

回到原本一對一聊天室時，接通中的通話會顯示完整浮窗、計時與可用背景。切到聊天列表、設定、聯絡人或其他聊天室時，只顯示靜態 compact 狀態與返回 / 掛斷操作，不顯示秒數，也不播放短影片。

视频通话详细说明

新功能

对应版本：v3.0.0

视频通话是 DreamChat 内的本地模拟互动，用来呈现角色来电、通话浮窗与通话事件。它不会开启真实摄像头或麦克风，也不是实际电话或网络视频通话。

设置方式拨打与来电主动来电App 外通知通话背景

1. 开启角色视频通话

路径：角色 → 角色设置 → 视频通话

  1. 开启角色的视频通话功能。
  2. 需要角色主动来电时，开启主动来电并选择频率。
  3. 到「设置 → 通知」调整视频通话铃声与全局勿扰时段。
  4. 设置通话背景。免费版可用静态图片，升级方案可用静态图片与短视频背景。

2. 用户拨打与「让他来电」

一对一聊天室可拨打角色；群组聊天第一版不显示视频通话入口。你也可以发出「让他来电」请求，系统会依角色回应与本地排程决定是否安排一次来电。

接通、未接、拒接、超时或用户取消，都会在聊天记录中留下通话事件。

3. 角色主动来电逻辑

角色可设置很少、普通、频繁或不固定等频率。候选时间到达后，系统会用自然延迟建立来电；接听期限约 60 秒。一般主动来电未接、拒接或超时后，约 30 到 60 分钟后可能安排一次重拨，重拨仍未接后才回到原本频率。

4. App 外不会像真实电话般响铃

DreamChat 不使用 CallKit、PushKit、VoIP push 或系统电话画面。App 在后台或不适合显示来电界面时，只会跳本地来电通知；不会像真实电话一样持续全屏响铃。

5. 通话背景与通话中切换

回到原本一对一聊天室时，接通中的通话会显示完整浮窗、计时与可用背景。切到聊天列表、设置、联系人或其他聊天室时，只显示静态 compact 状态与返回 / 挂断操作，不显示秒数，也不播放短视频。

ビデオ通話詳しい説明

新機能

対応バージョン：v3.0.0

ビデオ通話は DreamChat 内のローカルな模擬インタラクションです。キャラクターの着信、通話ウィンドウ、通話イベントを表現しますが、実際のカメラやマイクは使わず、電話やネットワーク通話でもありません。

設定発信と着信自発着信アプリ外通知背景

1. キャラクターのビデオ通話をオンにする

場所：キャラクター → キャラクター設定 → ビデオ通話

  1. キャラクターのビデオ通話を有効にします。
  2. キャラクターからの着信を使う場合は、自発着信をオンにして頻度を選びます。
  3. 「設定 → 通知」でビデオ通話の着信音と全体のサイレント時間を調整します。
  4. 通話背景を設定します。無料版は静止画、アップグレード済みプランは静止画と短い動画背景を使えます。

2. 発信と「あとでかけて」

1対1チャットからキャラクターに発信できます。グループチャットには初回版の入口は表示されません。「あとでかけて」と依頼すると、キャラクターの反応とローカルスケジュールに応じて一度だけ着信が予定されます。

応答、未応答、拒否、タイムアウト、キャンセルはチャット履歴の通話イベントとして残ります。

3. キャラクターからの着信ロジック

頻度は、少なめ、普通、多め、不定期から選べます。候補時刻になると自然な遅延の後に着信が作られ、応答期限は約60秒です。通常の着信で未応答、拒否、タイムアウトになった場合、30〜60分後に一度だけ再着信することがあります。

4. アプリ外では本物の電話のようには鳴りません

DreamChat は CallKit、PushKit、VoIP push、システム電話画面を使いません。アプリがバックグラウンドにある場合や着信画面を出せない場合は、ローカル通知で知らせます。本物の電話のように全画面で鳴り続けることはありません。

5. 通話背景と画面移動

元の1対1チャットに戻ると、接続中の通話は通常のウィンドウ、タイマー、利用可能な背景を表示します。チャット一覧、設定、連絡先、他のチャットでは静的な compact 表示と戻る / 終了操作だけを表示し、秒数や動画背景は再生しません。

Video Call Guide

New Feature

Applies to version v3.0.0

Video Call is a local simulated interaction inside DreamChat. It presents character calls, a call window, and call events. It does not use the real camera or microphone, and it is not a real phone or network video call.

SetupCallingIncoming LogicOutside AppBackgrounds

1. Enable Video Call for a Character

Path: Characters → Character Settings → Video Call

  1. Enable Video Call for the character.
  2. If you want character-initiated calls, enable incoming calls and choose a frequency.
  3. Open Settings → Notifications to adjust Video Call ringtone and global quiet hours.
  4. Set a call background. The free plan supports still images. Upgraded plans support still images and short video backgrounds.

2. Calling and Ask Them to Call Later

You can call a character from a one-on-one chat. Group chats do not show the first-version Video Call entry point. You can also ask a character to call later; the app decides whether to schedule a one-time call using local reply and scheduling logic.

Answered, missed, declined, timed-out, and canceled calls are saved as chat events.

3. Character Incoming Call Logic

Each character can use Rare, Normal, Frequent, or Irregular frequency. When a candidate time arrives, the app creates the call after a natural delay. The answer window is about 60 seconds. If a normal incoming call is missed, declined, or times out, one redial may be scheduled about 30 to 60 minutes later.

4. Outside the App, It Does Not Ring Like a Real Phone

DreamChat does not use CallKit, PushKit, VoIP push, or the system phone UI. When the app is in the background or cannot safely show the in-app call prompt, it only sends a local incoming-call notification. It will not keep ringing full-screen like a real phone call.

5. Call Backgrounds and Moving Around the App

In the original one-on-one chat, a connected call shows the full call window, timer, and available background. In chat list, settings, contacts, or another chat, the app shows only a static compact state with return / hang up actions. It does not show seconds or play short video backgrounds there.
