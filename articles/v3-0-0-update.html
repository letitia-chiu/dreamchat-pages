3.0.0 版本更新內容

即將推出

對應版本：v3.0.0

3.0.0 會把角色互動往更像日常陪伴的方向推進：角色可以用本機模擬視訊通話出現，也能在天氣、聊天情境、貼圖、匯出分享與長範圍截圖上有更完整的整理方式。

視訊通話 天氣提醒 聊天情境 分享檔與備份檔 截圖穩定性 通話背景

1. 模擬視訊通話與角色來電

一對一聊天將可撥打角色，或送出「讓他來電」請求。角色接通、未接、拒接與逾時會保留成聊天事件；App 外的來電提示則使用本機通知。

這是 DreamChat 內的本機模擬互動，不會開啟真實相機或麥克風，也不使用 CallKit、VoIP push、錄音、錄影或影音傳輸。

2. 天氣提醒與聊天中詢問天氣

角色可設定每日天氣來訊，也可在聊天中回覆目前天氣。手動選地區不需要定位權限；若選擇使用目前位置，DreamChat 只會在你明確操作後請求「使用 App 期間」位置權限。

WeatherKit 或目前天氣資料不可用時，App 會改用本地預設提醒，不會因資料暫時不可用而中斷整個角色互動。

3. 聊天情境可切換包含或排除標籤

聊天室情境標籤新增兩種模式：包含情境會讓角色回覆更容易使用符合所選標籤的字卡組；排除情境則會避開符合所選標籤的字卡組。切換包含 / 排除模式時，另一個模式下已選過的標籤會保留下來，不需要重新設定。

4. 分享檔與備份檔格式更新

貼圖管理將支援移動貼圖、匯出貼圖群組與匯入貼圖群組。新的 .dreamchatstickers 會把群組資料與貼圖圖片整理在同一個分享檔中，匯入時可先預覽並勾選要加入的群組。

.dreamchatcharacter 與 .dreamchatbackup 也會更新檔案格式，把主要資料與頭像、貼圖、通話背景等素材分開保存，讓匯出與匯入更穩定。

⚠ 注意：3.0.0 仍可匯入舊版角色檔與備份；舊版 App 可能無法讀取 3.0.0 匯出的新格式檔案。

5. 長範圍截圖選取更穩定

訊息截圖會改用明確的選取起點與固定範圍快照，支援起點上下各 50 則訊息內的長範圍選取。匿名截圖預覽看到的畫面，會更接近最後儲存或分享出去的圖片。

6. 通話背景與方案限制更清楚

每個角色可設定視訊通話開關、主動來電頻率與通話背景。免費版可使用靜態圖片；升級方案可使用靜態圖片與短影片背景。如果你開啟 iOS「減少動態效果」、短影片無法播放，或目前方案不支援短影片，通話畫面會改顯示靜態圖片。

3.0.0 版本更新内容

即将推出

对应版本：v3.0.0

3.0.0 会把角色互动往更像日常陪伴的方向推进：角色可以用本地模拟视频通话出现，也能在天气、聊天情境、表情包、导出分享与长范围截图上有更完整的整理方式。

视频通话 天气提醒 聊天情境 分享文件与备份文件 截图稳定性 通话背景

1. 模拟视频通话与角色来电

一对一聊天将可拨打角色，或发出「让他来电」请求。角色接通、未接、拒接与超时会保留成聊天事件；App 外的来电提示则使用本地通知。

这是 DreamChat 内的本地模拟互动，不会开启真实摄像头或麦克风，也不使用 CallKit、VoIP push、录音、录像或影音传输。

2. 天气提醒与聊天中询问天气

角色可设置每日天气来信，也可在聊天中回复当前天气。手动选择地区不需要定位权限；若选择使用当前位置，DreamChat 只会在你明确操作后请求「使用 App 期间」位置权限。

WeatherKit 或当前天气数据不可用时，App 会改用本地默认提醒，不会因为数据暂时不可用而中断整个角色互动。

3. 聊天情境可切换包含或排除标签

聊天室情境标签新增两种模式：包含情境会让角色回应更容易使用符合所选标签的字卡组；排除情境则会避开符合所选标签的字卡组。切换包含 / 排除模式时，另一个模式下已选过的标签会保留下来，不需要重新设置。

4. 分享文件与备份文件格式更新

表情包管理将支持移动表情、导出表情包群组与导入表情包群组。新的 .dreamchatstickers 会把群组数据与表情图片整理在同一个分享文件中，导入时可先预览并勾选要加入的群组。

.dreamchatcharacter 与 .dreamchatbackup 也会更新文件格式，把主要数据与头像、表情包、通话背景等素材分开保存，让导出与导入更稳定。

⚠ 注意：3.0.0 仍可导入旧版角色文件与备份；旧版 App 可能无法读取 3.0.0 导出的新格式文件。

5. 长范围截图选择更稳定

消息截图会改用明确的选择起点与固定范围快照，支持起点上下各 50 条消息内的长范围选择。匿名截图预览看到的画面，会更接近最后保存或分享出去的图片。

6. 通话背景与方案限制更清楚

每个角色可设置视频通话开关、主动来电频率与通话背景。免费版可使用静态图片；升级方案可使用静态图片与短视频背景。如果你打开 iOS“减弱动态效果”、短视频无法播放，或当前方案不支持短视频，通话画面会改显示静态图片。

3.0.0 アップデート内容

近日公開

対応バージョン：v3.0.0

3.0.0 では、キャラクターとのやりとりを日常のそばに感じられるように整えます。ローカルの模擬ビデオ通話、天気リマインダー、チャットのコンテキスト、スタンプ共有、書き出し、長い範囲のスクリーンショットが主な変更です。

ビデオ通話 天気リマインダー コンテキスト 共有ファイルとバックアップ スクリーンショット 通話背景

1. 模擬ビデオ通話とキャラクターからの着信

1対1のチャットでキャラクターに発信したり、「あとでかけて」と依頼したりできるようになります。応答、未応答、拒否、タイムアウトはチャットイベントとして残り、アプリ外の着信案内にはローカル通知を使います。

これは DreamChat 内のローカルな演出です。実際のカメラやマイクは使用せず、CallKit、VoIP push、録音、録画、音声・映像の送受信も行いません。

2. 天気リマインダーとチャット内の天気質問

キャラクターごとに毎日の天気メッセージを設定でき、チャット内で現在の天気をたずねることもできます。手動で地域を選ぶ場合、位置情報権限は不要です。現在地を使う場合のみ、明示的な操作の後に「App の使用中」の位置情報権限を求めます。

WeatherKit または現在の天気データが利用できない場合は、端末内の既定リマインダーを使います。一時的に天気データを取得できなくても、キャラクターとのやりとり全体は止まりません。

3. チャットのコンテキストで含める / 除外するタグを切り替え

チャットのコンテキストタグに2つのモードを追加しました。「含める」では、選んだタグに合う定型文セットが使われやすくなります。「除外」では、選んだタグに合う定型文セットを避けます。モードを切り替えても、もう一方のモードで選んだタグは残るため、設定し直す必要はありません。

4. 共有ファイルとバックアップファイルの形式を更新

スタンプ管理では、スタンプの移動、スタンプグループの書き出し、読み込みに対応します。新しい .dreamchatstickers は、グループ情報とスタンプ画像を1つの共有ファイルにまとめ、読み込み前にプレビューして追加するグループを選べます。

.dreamchatcharacter と .dreamchatbackup もファイル形式を更新し、主要データとアバター、スタンプ、通話背景などの素材を分けて保存することで、書き出しと読み込みをより安定させます。

⚠ 注意：3.0.0 は旧形式のキャラクターファイルやバックアップも読み込めますが、旧バージョンのアプリでは 3.0.0 で書き出した新形式のファイルを読めない場合があります。

5. 長い範囲のスクリーンショット選択を安定化

メッセージスクリーンショットは、明確な開始位置と固定された範囲スナップショットを使うようになります。開始位置の前後50件までを対象に選択でき、匿名プレビューで見た画面が、保存または共有される画像により近くなります。

6. 通話背景とプラン制限を分かりやすく

キャラクターごとにビデオ通話の有効化、着信頻度、通話背景を設定できます。無料版では静止画、アップグレード済みプランでは静止画と短い動画背景を使えます。iOS の「視差効果を減らす」がオンの場合、動画を再生できない場合、または現在のプランで動画背景を使えない場合は、通話画面に静止画が表示されます。

What's New in 3.0.0

Coming Soon

Applies to version v3.0.0

3.0.0 moves DreamChat closer to everyday character companionship with local simulated video calls, weather reminders, chat context controls, sticker sharing, updated export files, and steadier long-range screenshots.

Video Calls Weather Chat Context Share and Backup Files Screenshots Call Backgrounds

1. Simulated Video Calls and Character Callbacks

In one-on-one chats, you will be able to call a character or ask them to call later. Answered, missed, declined, and timed-out calls are saved as chat events. Outside the app, incoming-call prompts use local notifications.

This is a local in-app simulation. DreamChat does not use the real camera or microphone, CallKit, VoIP push, recording, or audio/video transmission.

2. Weather Reminders and In-Chat Weather Questions

Characters can send a daily weather message and answer current-weather questions in chat. Manual region selection does not require location permission. If you choose to use your current location, DreamChat asks for When In Use permission only after that explicit action.

When WeatherKit or current-weather data is unavailable, the app uses a local default reminder so the character interaction can continue.

3. Include or Exclude Tags in Chat Contexts

Chat context tags now have two modes. Include makes replies more likely to use phrase groups that match the selected tags. Exclude avoids phrase groups that match the selected tags. Switching modes keeps the tags you selected in the other mode, so you do not need to set them up again.

4. Updated Share and Backup File Formats

Sticker Management will support moving stickers plus exporting and importing sticker groups. The new .dreamchatstickers file keeps group data and sticker images together in one share file, with preview and selection before import.

.dreamchatcharacter and .dreamchatbackup also use updated file formats that separate primary data from assets such as avatars, stickers, and call backgrounds, making export and import more stable.

⚠ Note: 3.0.0 can still import older character files and backups, but older app versions may not be able to read new-format files exported from 3.0.0.

5. Steadier Long-Range Screenshot Selection

Message screenshots now use an explicit anchor and a frozen selection window, supporting longer selections within 50 messages above or below the anchor. Anonymous preview now looks closer to the image you save or share.

6. Clearer Call Backgrounds and Plan Limits

Each character can control Video Call availability, incoming call frequency, and call background. The free plan can use still images. Upgraded plans can use still images and short video backgrounds. If iOS Reduce Motion is on, a short video cannot play, or your current plan does not support video backgrounds, the call screen shows a still image instead.
