天氣提醒詳細說明

新功能

對應版本：v3.0.0

天氣提醒可以讓角色每天用自己的語氣提醒天氣，也能在聊天中回覆目前天氣。設定保存在裝置本機，手動選地區不需要定位權限。

設定方式地區聊天詢問提醒字卡資料不可用

1. 開啟天氣提醒

路徑：角色 → 角色設定 → 天氣提醒

  1. 開啟「啟用提醒」。
  2. 選擇提醒要送到哪一個一對一聊天室。
  3. 設定提醒時間；需要自然一點時，可加入時間浮動。
  4. 設定地區後儲存。沒有有效地區時，設定可先保存，但不會送出天氣提醒或聊天天氣回覆。

2. 選擇手動地區或目前位置

「手動選擇地區」適合固定查看城市或旅行地點，搜尋城市或地區後選取即可，不會要求定位權限。

「自動所在地區」會在你按下使用目前位置後，才請求「使用 App 期間」位置權限。若位置刷新失敗，App 會優先使用已保存的位置；沒有可用地區時會改用本地預設提醒。

3. 在聊天中詢問目前天氣

開啟「在聊天中詢問」後，角色可依關鍵字回覆目前天氣。你可以加入「天氣」、「氣溫」、「下雨」、「帶傘」這類關鍵字，也可以開啟「觸發天氣回覆時，不傳送其他回覆」，讓命中天氣詢問時只送天氣訊息。

4. 調整提醒字卡

天氣提醒會依氣溫狀況與天氣狀況選擇文字，例如炎熱、微涼、雨勢較明顯、風比較大。你可以進入各狀況修改角色會說的句子，每個狀況最多保留 5 句。

字卡怎麼寫會影響最後組句是否自然。溫度狀況與天氣狀況的組句技巧請看 天氣提醒專用字卡設定技巧。

5. WeatherKit 或資料暫時不可用時

DreamChat 會嘗試使用可用的天氣資料；若 WeatherKit、目前天氣或地區資料暫時不可用，會使用本地 fallback/default reminder，不承諾固定文句，也不會把天氣設定上傳到開發者伺服器。

天气提醒详细说明

新功能

对应版本：v3.0.0

天气提醒可以让角色每天用自己的语气提醒天气，也能在聊天中回复当前天气。设置保存在设备本机，手动选地区不需要定位权限。

设置方式地区聊天询问提醒字卡资料不可用

1. 开启天气提醒

路径：角色 → 角色设置 → 天气提醒

  1. 开启「启用提醒」。
  2. 选择提醒要送到哪一个一对一聊天室。
  3. 设置提醒时间；需要自然一点时，可加入时间浮动。
  4. 设置地区后保存。没有有效地区时，设置可先保存，但不会发送天气提醒或聊天天气回复。

2. 选择手动地区或当前位置

「手动选择地区」适合固定查看城市或旅行地点，搜索城市或地区后选取即可，不会要求定位权限。

「自动所在地」会在你点使用当前位置后，才请求「使用 App 期间」位置权限。若位置刷新失败，App 会优先使用已保存的位置；没有可用地区时会改用本地默认提醒。

3. 在聊天中询问当前天气

开启「在聊天中询问」后，角色可依关键词回复当前天气。你可以加入「天气」、「气温」、「下雨」、「带伞」这类关键词，也可以开启「触发天气回复时，不发送其他回复」，让命中天气询问时只发送天气消息。

4. 调整提醒字卡

天气提醒会依气温状况与天气状况选择文字，例如炎热、微凉、雨势较明显、风比较大。你可以进入各状况修改角色会说的句子，每个状况最多保留 5 句。

字卡怎么写会影响最后组句是否自然。温度状况与天气状况的组句技巧请看 天气提醒专用字卡设置技巧。

5. WeatherKit 或资料暂时不可用时

DreamChat 会尝试使用可用的天气资料；若 WeatherKit、当前天气或地区资料暂时不可用，会使用本地 fallback/default reminder，不承诺固定文句，也不会把天气设置上传到开发者服务器。

天気リマインダー詳しい説明

新機能

対応バージョン：v3.0.0

天気リマインダーでは、キャラクターが毎日そのキャラクターらしい言葉で天気を知らせたり、チャット内で現在の天気に答えたりできます。設定は端末内に保存され、手動で地域を選ぶ場合は位置情報権限を使いません。

設定地域チャット質問定型文取得できない場合

1. 天気リマインダーをオンにする

場所：キャラクター → キャラクター設定 → 天気リマインダー

  1. 「リマインダーをオン」を有効にします。
  2. 送信先の1対1チャットを選びます。
  3. 通知時刻を設定します。自然に見せたい場合は時間のゆらぎも設定できます。
  4. 地域を設定して保存します。有効な地域がない場合、設定は保存できますが、リマインダーやチャット内の天気返信は送信されません。

2. 手動地域または現在地を選ぶ

「地域を手動で選択」は、決まった都市や旅行先を見たいときに使います。都市や地域を検索して選ぶだけで、位置情報権限は不要です。

「現在地を自動判定」は、現在地を使う操作をした後にだけ「App の使用中」の位置情報権限を求めます。更新に失敗した場合は保存済みの位置を優先し、使える地域がなければ端末内の既定リマインダーに切り替わります。

3. チャット内で現在の天気を聞く

「チャット内で質問」をオンにすると、キャラクターはキーワードに応じて現在の天気を返せます。「天気」「気温」「雨」「傘」などのキーワードを追加できます。「天気の返信が発生したとき、他の返信を送らない」をオンにすると、天気に該当したときは天気メッセージだけを送ります。

4. リマインダー定型文を調整する

天気リマインダーは、暑い、少し涼しい、雨が強め、風が強めなど、気温の状態と天気の状態に合わせて文を選びます。各状態の文は編集でき、1つの状態につき最大5件まで保存できます。

定型文の書き方で、最後の文の自然さが変わります。気温と天気の組み合わせ方は 天気リマインダー専用定型文のコツをご覧ください。

5. WeatherKit やデータが一時的に使えない場合

DreamChat は利用できる天気データを使います。WeatherKit、現在の天気、地域データが一時的に使えない場合は、端末内の fallback/default reminder を使います。固定の文面は保証せず、天気設定を開発者サーバーへアップロードしません。

Weather Reminder Guide

New Feature

Applies to version v3.0.0

Weather Reminder lets a character send a daily weather note in their own tone and answer current-weather questions in chat. Settings stay on your device, and manual region selection does not require location permission.

SetupRegionAsk in ChatPhrasesUnavailable Data

1. Turn On Weather Reminder

Path: Characters → Character Settings → Weather Reminder

  1. Enable Reminder.
  2. Choose the one-on-one chat where the reminder should be sent.
  3. Set the reminder time. Add time variation if you want it to feel less exact.
  4. Set a region and save. Without a valid region, the settings can be saved, but reminders and chat weather replies will not be sent.

2. Choose Manual Region or Current Location

Manual region is for a fixed city or travel destination. Search for a city or region and select it; no location permission is requested.

Automatic uses your current location only after you explicitly choose to use it, then asks for When In Use location permission. If refresh fails, the app tries the saved coordinates first. If no usable region is available, it falls back to a local default reminder.

3. Ask About Current Weather in Chat

When Ask in Chat is enabled, the character can answer current-weather prompts that match keywords. Add keywords such as weather, temperature, rain, or umbrella. You can also enable Send only the weather reply when triggered so a matched weather question sends only the weather message.

4. Adjust Weather Reminder Phrases

Weather Reminder chooses phrases from temperature conditions and weather conditions, such as Hot, Cool, Rain, or Windy. You can edit the lines for each condition, with up to 5 phrases per condition.

Phrase wording affects how natural the final sentence feels. For temperature and weather phrase composition, see Weather Reminder Phrase Tips.

5. When WeatherKit or Weather Data Is Unavailable

DreamChat uses available weather data when it can. If WeatherKit, current weather, or region data is temporarily unavailable, it uses a local fallback/default reminder. It does not promise a fixed fallback sentence, and weather settings are not uploaded to the developer's servers.
