聊天模式詳細說明

對應版本：v2.7.0

聊天模式決定角色收到訊息後會用哪一種方式回覆。你可以依照對話目的，在一般聊天、簡短判斷與隨機選項之間切換。

模式總覽 聊天模式 是否模式 幫我選 切換位置

1. 三種常見用法

  • 聊天模式：從角色的字卡庫抽取回覆，適合日常聊天、角色語氣與較完整的互動。
  • 是否模式：固定回覆簡短判斷，適合問「要不要」「可不可以」「是不是」這類問題。
  • 幫我選：你輸入題目與選項，DreamChat 會從選項中抽一個作為角色回覆。

2. 聊天模式

聊天模式會從目前角色的字卡庫中選擇回覆。字卡內容、字卡組設定、情境標籤與智慧輔助設定，都會影響角色回覆時更容易選到哪一組字卡。

  • 至少需要一張可用字卡；字卡庫是空的時候，角色不會自動產生文字回覆。
  • 想快速開始，可以先到字卡庫的「匯出／匯入」選單套用預設範本。
  • 想讓角色更像你設定的個性，請把常見語氣、日常回覆與情境回覆整理成字卡。

3. 是否模式

是否模式不會從字卡庫抽句子，而是用固定答案組回覆。主要有三種回覆方向：

  • 肯定：是、好、要、在、有、可以這類答案。
  • 否定：不是、不好、不要、不在、沒有、不可以這類答案。
  • 不確定：不好說、不能回答、保留意見這類答案。

另外還有一個低機率的隱藏回覆，留給你在聊天時慢慢發掘。

4. 幫我選

「幫我選」適合讓角色從你提供的選項中挑一個。它不會永久改變聊天模式，只會把這次題目與選項送進聊天室，再安排角色回覆其中一個選項。

  1. 在聊天室右上角選單按「幫我選」。
  2. 輸入題目，例如「今晚要吃什麼？」
  3. 輸入至少兩個選項後送出。

5. 在哪裡切換

路徑：聊天 → 開啟對話 → 右上角選單 → 聊天模式

你也可以到角色設定中調整角色的預設聊天模式。若只是想臨時做選擇題，使用「幫我選」通常更直接。

聊天模式详细说明

对应版本：v2.7.0

聊天模式决定角色收到消息后会用哪一种方式回复。你可以依照对话目的，在一般聊天、简短判断与随机选项之间切换。

模式总览 聊天模式 是否模式 帮我选 切换位置

1. 三种常见用法

  • 聊天模式：从角色的字卡库抽取回复，适合日常聊天、角色语气与较完整的互动。
  • 是否模式：固定回复简短判断，适合问「要不要」「可不可以」「是不是」这类问题。
  • 帮我选：你输入题目与选项，DreamChat 会从选项中抽一个作为角色回复。

2. 聊天模式

聊天模式会从当前角色的字卡库中选择回复。字卡内容、字卡组设置、情境标签与智能辅助设置，都会影响角色回复时更容易选到哪一组字卡。

  • 至少需要一张可用字卡；字卡库为空时，角色不会自动生成文字回复。
  • 想快速开始，可以先到字卡库的「导出／导入」菜单应用预设模板。
  • 想让角色更像你设置的个性，请把常见语气、日常回复与情境回复整理成字卡。

3. 是否模式

是否模式不会从字卡库抽句子，而是用固定答案组回复。主要有三种回复方向：

  • 肯定：是、好、要、在、有、可以这类答案。
  • 否定：不是、不好、不要、不在、没有、不可以这类答案。
  • 不确定：不好说、不能回答、保留意见这类答案。

另外还有一个低概率的隐藏回复，留给你在聊天时慢慢发掘。

4. 帮我选

「帮我选」适合让角色从你提供的选项中挑一个。它不会永久改变聊天模式，只会把这次题目与选项送进聊天室，再安排角色回复其中一个选项。

  1. 在聊天室右上角菜单按「帮我选」。
  2. 输入题目，例如「今晚要吃什么？」
  3. 输入至少两个选项后发送。

5. 在哪里切换

路径：聊天 → 打开对话 → 右上角菜单 → 聊天模式

你也可以到角色设置中调整角色的默认聊天模式。若只是想临时做选择题，使用「帮我选」通常更直接。

チャットモードの詳しい説明

対応バージョン：v2.7.0

チャットモードは、キャラクターがメッセージを受け取ったあと、どの方法で返事をするかを決める設定です。会話の目的に合わせて、通常の会話、短い判断、ランダムな選択を使い分けられます。

概要 チャットモード はい/いいえ 選んで 切り替え場所

1. よく使う3つの使い方

  • チャットモード：キャラクターの定型文集から返信を選びます。日常会話、キャラクターらしい口調、長めのやり取りに向いています。
  • はい/いいえモード：短い判断で返信します。「する？」「できる？」「そうなの？」のような質問に向いています。
  • 選んで：質問と選択肢を入力すると、DreamChat が選択肢から1つをキャラクターの返信として選びます。

2. チャットモード

チャットモードでは、現在のキャラクターの定型文集から返信が選ばれます。定型文の内容、定型文セットの設定、コンテキストタグ、スマートアシスト設定が、どのセットから選ばれやすいかに影響します。

  • 少なくとも1件の使用可能な定型文が必要です。定型文集が空の場合、キャラクターは文字の自動返信を行いません。
  • すぐ始めたい場合は、定型文集の「書き出し／読み込み」メニューからサンプルテンプレートを適用できます。
  • キャラクターらしさを出したい場合は、よく使う口調、日常返信、状況別の返信を定型文として整理します。

3. はい/いいえモード

はい/いいえモードは定型文集から文章を選ばず、固定の回答グループで返信します。主な返信方向は3つです。

  • 肯定：はい、いいよ、いる、ある、できる、など。
  • 否定：いいえ、よくない、いらない、いない、ない、できない、など。
  • 保留：わからない、なんとも言えない、答えられない、保留、など。

ほかにも低い確率で出る隠し返信があります。チャットの中で見つけてみてください。

4. 選んで

「選んで」は、あなたが用意した選択肢からキャラクターに1つ選ばせたいときに使います。チャットモードを恒久的に変更するものではなく、その質問と選択肢をチャットに送り、キャラクターがその中から返信します。

  1. チャット右上のメニューで「選んで」を押します。
  2. 「今夜何を食べる？」のように質問を入力します。
  3. 2つ以上の選択肢を入力して送信します。

5. どこで切り替えるか

場所：チャット → 会話を開く → 右上メニュー → チャットモード

キャラクター設定でも、キャラクターの既定チャットモードを変更できます。一時的に選択肢を選ばせたいだけなら、「選んで」を使うほうが直接的です。

Chat Modes Guide

Applies to version v2.7.0

Chat modes decide how a character replies after receiving a message. You can switch between open-ended chat, short judgment replies, and random choices depending on the conversation.

Overview Chat Mode Yes/No Mode Choose for Me Where to Switch

1. Three Common Uses

  • Chat Mode: chooses replies from the character's Chat Phrases, best for everyday chat, character voice, and fuller interactions.
  • Yes/No Mode: replies with short judgment answers, best for questions like "should we", "can you", or "is it".
  • Choose for Me: you enter a question and options, and DreamChat picks one option as the character's reply.

2. Chat Mode

Chat Mode chooses replies from the current character's Chat Phrases. Phrase text, phrase set settings, context tags, and Smart Assist settings can all affect which set is easier to pick.

  • At least one usable chat phrase is required. If the phrase library is empty, the character will not send an automatic text reply.
  • To begin quickly, open the Chat Phrases Export / Import menu and apply the default template.
  • For a stronger character voice, organize common tone, everyday replies, and situation-specific replies as chat phrases.

3. Yes/No Mode

Yes/No Mode does not pick sentences from Chat Phrases. It replies with fixed answer groups. There are three main reply directions:

  • Positive: yes, OK, I do, here, have it, can do.
  • Negative: no, not OK, I don't, not here, don't have it, can't.
  • Unsure: not sure, hard to say, can't answer, no comment.

There is also a low-probability hidden reply for you to discover while chatting.

4. Choose for Me

Choose for Me is for letting a character pick from options you provide. It does not permanently change the chat mode; it sends this question and its options into the chat, then schedules the character to reply with one of the options.

  1. Open the top-right menu in a chat and tap Choose for Me.
  2. Enter a question, such as "What should we eat tonight?"
  3. Enter at least two options and submit.

5. Where to Switch

Path: Chat → Open a conversation → Top-right menu → Chat Mode

You can also change a character's default chat mode in character settings. If you only want a temporary choice question, Choose for Me is usually more direct.
